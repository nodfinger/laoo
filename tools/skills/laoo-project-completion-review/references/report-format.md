# Completion report format

Use one row per menu:

| MenuCode | MenuName | ScreenType | UI | API | Permission | Integration | Status |
|---|---|---:|---|---|---|---|---|

Then report:

1. Changes made, grouped by Project and shared contract.
2. Test data and run identifier.
3. Commands and observable results.
4. Cross-project workflows proven from source through destination.
5. Remaining blockers, required approval, and impact.
6. API/Flutter runtime status and `http://localhost:8080` when opened.

Never label a menu complete from source inspection alone. `พร้อมใช้งาน` requires passing behavior and integration evidence.
