# แบบร่างหน้ากำหนดค่าระบบอนุมัติข้อมูล-เอกสาร

ระบบการอนุมัติข้อมูล-เอกสาร เปิดหรือปิดแยกตามบริษัท

```text
┌─────────────────────────────────────────────────────────────────┐
│ ⚙ กำหนดค่าระบบ                                                │
└─────────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────────┐
│                  หน้าจออยู่ระหว่างพัฒนา                         │
└─────────────────────────────────────────────────────────────────┘
```

- หน้าจอเต็ม ScreenType 2 ใช้สี ขนาดตัวอักษร และระยะห่างตาม User Style
- พ่อยืนยันให้หน้ากำหนดค่าระบบใหม่เป็นหน้าว่างก่อน; ค่าจัดระดับตำแหน่งเดิมยังอยู่หน้ากำหนดค่าระบบส่วนกลาง
- เมนูรูปแบบการอนุมัติใช้ MenuCode 10011 เดิม ย้ายมาอยู่ในระบบใหม่
- เมนูใหม่นี้ไม่รองรับการพิมพ์หรือส่งออก
- สิทธิ์และแพ็กเกจตรวจทั้งหน้าจอและ Backend ส่วนตัวคำนวณการส่งอนุมัติจริงยังต้องพัฒนาเชื่อมต่อในงานถัดไป
