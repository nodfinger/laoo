# แบบร่าง: การเข้าถึงข้อมูล

เมนูที่เสนอ: `10010` · ScreenType `3` · กลุ่มสิทธิ์การใช้งาน

```text
┌──────────────────────────────────────────────────────────────┐
│ ไอคอน  การเข้าถึงข้อมูล ☆                                  │
└──────────────────────────────────────────────────────────────┘
┌──────────────────────────────────────────────────────────────┐
│ [ค้นหาชื่อระบบหรือเมนู       ] [ค้นหา] [ล้าง Filter]      │
└──────────────────────────────────────────────────────────────┘
┌──────────────────────────────────────────────────────────────┐
│ ระบบ          │ เมนู              │ นโยบาย │ กำหนดค่า      │
│ แจ้งซ่อม       │ แจ้งซ่อม          │ ส่วนกลาง│ [กำหนด]       │
│ ห้องประชุม    │ จองห้องประชุม     │ ส่วนกลาง│ [กำหนด]       │
│ ระบบของฉัน   │ เบิกค่าเดินทาง    │ ส่วนกลาง│ [กำหนด]       │
└──────────────────────────────────────────────────────────────┘
┌──────────────────────────────────────────────────────────────┐
│ [‹] [1] [›]  1–3 จาก 3                                     │
└──────────────────────────────────────────────────────────────┘
```

Popup กำหนดค่าแสดงชื่อเมนู ปุ่มคืนค่าเริ่มต้นส่วนกลาง และตัวเลือกการดู แก้ไข และลบ โดยแต่ละอย่างกำหนดขอบเขตและสิทธิ์หัวหน้า/ผู้จัดการได้ จากนั้นกดบันทึกหรือยกเลิก การตั้งค่าของแต่ละเมนูแยกกันและไม่แก้ค่าส่วนกลาง

หน้าจอนี้เป็น ScreenType 3 ตามคำสั่ง การเปลี่ยนนโยบายผ่าน Popup ต้องใช้สิทธิ์บริหารสิทธิ์แยกต่างหาก และ API ต้องตรวจสิทธิ์ดังกล่าวซ้ำก่อนบันทึก
