# OCR นามบัตร — ผลตรวจ Draft

วันที่: 5 ตุลาคม 2026

## สิ่งที่พร้อมตรวจ Layout

เปิด `business-card-ocr-draft.html` โดยตรงใน Chrome/Edge; ใช้ Font จาก
`../../assets/fonts/NotoSansThai-Variable.ttf` ไม่มี CDN และไม่เชื่อม API

- อ่านนามบัตร: ภาพด้านหน้า/หลัง หมุนภาพ แสดงกรอบครอบภาพ และแนบรูปจากเครื่อง/กล้อง
- ตรวจผล: เลือกข้อมูลที่จะนำเข้า แก้ช่อง เลือกบรรทัดข้อความต้นฉบับ และตรวจรายการที่อาจซ้ำ
- ปลายทางลูกค้า: เลือกผู้ติดต่อคนที่ 1/2 โดยแยกการเก็บค่าจำลอง ไม่ทับอีกคน
- ปลายทางผู้ติดต่อ: List/Card, ค้นหา, Pagination, Popup เพิ่ม/แก้ไข และเชื่อมลูกค้า
- ปลายทาง Visitor: จำลองนำเข้าชื่อและโทรศัพท์ พร้อมแจ้งช่องที่ไม่รองรับ
- ตั้งค่า OCR: เปิด/ปิด จำกัดภาพ และเวลาประมวลผล; TimeAlert เป็นตัวทดลองจากส่วนกลาง
- Caption เรียงไอคอน → ชื่อ → ดาว; Action อยู่ขวา มุม 4px
- Popup กว้างไม่เกิน 480px, เว้นขอบ 24px, ปุ่มสูง 48px; Content เลื่อนแยก Header/Footer

## ผลทดสอบ

รัน `python tools/tests/ocr-draft-browser.py` ด้วย Playwright บน Chrome ที่ติดตั้งในเครื่อง:

- ผ่าน 99 จุดตรวจ; ไม่พบ JavaScript error
- ตรวจ 1440, 1024, 768, 430 และ 360px: ไม่พบ document overflow
- ตรวจ Popup ทั้งสามปลายทาง: ความกว้าง ปุ่ม และ Footer อยู่ใน viewport
- ทดสอบ Search ด้วย Enter, Empty, Pagination, List/Card, เมนูลัด และ Theme 3 โทน
- ทดสอบเพิ่มแล้วล้างฟอร์ม/เปิดค้าง, แก้ไขแล้วปิด, เลือกผู้ติดต่อคนที่ 2 โดยไม่ทับคนที่ 1
- ทดสอบต้องยืนยันผลก่อนนำเข้า และยกเลิกการเขียนทับแล้วข้อมูลเดิมไม่เปลี่ยน
- ทดสอบนามบัตรไทย อังกฤษ หลายเบอร์ ข้อมูลไม่ครบ อ่านไม่พบ หมดเวลา และเครื่องมือขัดข้องแบบจำลอง
- ทดสอบไฟล์ผิดชนิด เกิน 10 MB และเปลี่ยนรูปแล้วล้างผลอ่านเก่า
- ตรวจ Alert หายตามเวลาที่ตั้ง, ปิด OCR แล้วกดอ่านไม่ได้, Keyboard focus
- ไม่พบ HTTP/HTTPS request; ไม่มีการอ่าน/เขียนฐานข้อมูลจาก Draft

ตรวจภาพ screenshot Desktop และ Mobile popup ด้วยตาแล้ว ภาพหลักฐานแต่ละรอบอยู่ใน
temporary directory ที่สคริปต์รายงาน ไม่เพิ่ม build artifact เข้า Git

## ขอบเขตที่ยังไม่ใช่ระบบจริง

- OCR เป็นข้อมูลตัวอย่าง แม้ผู้ใช้แนบภาพจริง; ยังไม่ได้ติดตั้ง/เรียก Tesseract
- กรอบครอบภาพเป็นตัวอย่าง Layout ไม่แก้ไฟล์ต้นฉบับ
- ข้อมูลเก็บเฉพาะหน่วยความจำหน้าเว็บ รีโหลดแล้วกลับสู่ตัวอย่าง
- ตัวอย่างทะเบียนลูกค้า/Visitor แสดงเฉพาะช่องที่เกี่ยวกับ OCR ไม่แทนหน้าธุรกิจจริงทั้งหมด
- ค่า timeout เป็นแบบฟอร์มจำลอง; กรณี timeout อ่านจาก scenario ตัวอย่าง
- กล้องจริง/HTTPS, Touch บนอุปกรณ์จริง, OCR accuracy, Permission/API และฐานจริงยังไม่ทดสอบ
- ติดตั้งเพิ่มเฉพาะ Playwright ใน Python user environment เพื่อทดสอบ Draft
