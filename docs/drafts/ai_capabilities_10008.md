# แบบร่าง: จัดการความสามารถ AI

MenuCode: `10008` · ScreenType: `1` · เมนู: ตั้งค่าระบบ

เอกสารนี้เป็นแบบร่างเพื่อทบทวนตำแหน่ง Field และขั้นตอนใช้งาน ตัวอย่างข้อมูลไม่ใช่ข้อมูลจริงและยังไม่มีการเชื่อมต่อระบบ

## หน้ารายการแบบ List

```text
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│ [ไอคอน] จัดการความสามารถ AI  ☆                                      [สลับ List/Card]       │
└───────────────────────────────────────────────────────────────────────────────────────────┘
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│ [ค้นหาชื่อหรือคำอธิบาย                  ] [ค้นหา] [ล้าง Filter] [ระบบ: ทั้งหมด ▼] [สถานะ: ทั้งหมด ▼] │
└───────────────────────────────────────────────────────────────────────────────────────────┘
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│ ID │ Action │ ชื่อความสามารถ              │ ระบบ          │ ตัวอย่างคำถาม           │ สถานะ   │
├────┼────────┼─────────────────────────────┼───────────────┼─────────────────────────┼─────────┤
│ 1  │ [แก้ไข] │ ติดตามงานซ่อมของฉัน         │ ระบบแจ้งซ่อม │ งานซ่อมของฉันถึงไหน    │ เปิด     │
│ 2  │ [แก้ไข] │ สรุปค่าอะไหล่งานซ่อม        │ ระบบแจ้งซ่อม │ ค่าอะไหล่เดือนนี้เท่าไร │ ปิด      │
│ 3  │ [แก้ไข] │ แจ้งงานซ่อมใหม่             │ ระบบแจ้งซ่อม │ แจ้งซ่อมเครื่องพิมพ์    │ ปิด      │
└────┴────────┴─────────────────────────────┴───────────────┴─────────────────────────┴─────────┘
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│ [‹] [1] [›]  1–3 จาก 3                                                                     │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```

- รายการมาจากความสามารถที่ติดตั้งในระบบแล้ว ผู้ดูแลไม่สร้างตัวทำงานใหม่ผ่านหน้าจอ
- ปุ่มแก้ไขแสดงตามสิทธิ์ `EDIT` ของเมนู `10008`; ผู้มีสิทธิ์ `VIEW` ค้นหาและดูรายการได้
- Filter ระบบและสถานะมีตัวเลือก `ทั้งหมด`; ค้นหาและล้าง Filter ใช้รูปแบบส่วนกลาง
- สีไอคอน ปุ่ม และสถานะปกติใช้ User Style; สถานะปิดใช้สีตามมาตรฐานสถานะ
- หาก Company ปิด AI Chat จะไม่แสดงเมนูนี้และ API ปฏิเสธการเข้าถึง โดยเก็บค่าที่ตั้งไว้

## หน้ารายการแบบ Card

```text
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│ ติดตามงานซ่อมของฉัน                                            [เปิด]  [แก้ไข]              │
│ ระบบ: ระบบแจ้งซ่อม                                                                       │
│ แสดงเลขที่ หัวข้อ และสถานะงานที่ผู้ใช้สร้าง                                                │
│ ตัวอย่าง: งานซ่อมของฉันถึงไหน                                                             │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```

การสลับ List/Card ใช้ Filter และข้อมูลชุดเดียวกัน ปุ่มและระยะห่างยึดมาตรฐานส่วนกลาง

## Popup แก้ไขความสามารถ

```text
┌────────────────────────────────────────────────────────────┐
│ [ไอคอน] จัดการความสามารถ AI > แก้ไข                         │
├────────────────────────────────────────────────────────────┤
│ สถานะการใช้งานในบริษัท  [เปิด/ปิด]                         │
│                                                            │
│ ชื่อความสามารถ *                                           │
│ [สรุปค่าอะไหล่งานซ่อม                                   ] │
│                                                            │
│ คำอธิบาย                                                   │
│ [สรุปต้นทุนอะไหล่ของงานที่เสร็จตามช่วงวันที่            ] │
│                                                            │
│ ตัวอย่างคำถาม                              [+ เพิ่มตัวอย่าง] │
│ [ค่าอะไหล่เดือนนี้เท่าไร                            ] [ลบ] │
│ [เคยใช้ค่าอะไหล่ซ่อมทั้งหมดเท่าไร                  ] [ลบ] │
│                                                            │
│ รูปแบบคำตอบที่อนุญาต                                       │
│ [✓] ข้อความใน Chat  [✓] PDF  [✓] รูปภาพ PNG  [✓] HTML     │
│ [✓] ส่งอีเมล                                               │
│                                                            │
│ ข้อมูลการตรวจสิทธิ์ (อ่านอย่างเดียว)                        │
│ ระบบ: ระบบแจ้งซ่อม                                        │
│ เมนูและคำสั่ง: ตามความสามารถที่ติดตั้งและสิทธิ์ผู้ใช้       │
├────────────────────────────────────────────────────────────┤
│                                      [ยกเลิก]  [บันทึก]   │
└────────────────────────────────────────────────────────────┘
```

- ชื่อ คำอธิบาย ตัวอย่างคำถาม และสถานะเป็นค่าของ Company ปัจจุบัน
- `+ เพิ่มตัวอย่าง` เพิ่มช่องคำถามภายใน Popup; ปุ่มลบลบเฉพาะตัวอย่างที่เลือก เมื่อกดบันทึกจึงจัดเก็บ
- ผู้ดูแลเลือกเปิดรูปแบบคำตอบได้เฉพาะรูปแบบที่ตัวทำงานของความสามารถนั้นรองรับ; ข้อความใน Chat เปิดเสมอ
- ผู้ดูแลเปิดหรือปิดตัวเลือกส่งอีเมลแยกสำหรับความสามารถที่รองรับได้
- Project, MenuCode, ScreenType, Action และตัวทำงานเป็นค่าจาก Backend อ่านอย่างเดียว ไม่รับ SQL หรือ URL จากหน้าจอ
- เมื่อบันทึกสำเร็จ ปิด Popup กลับหน้ารายการและแสดงแจ้งเตือนตามมาตรฐาน; ยกเลิกไม่บันทึก
- Header และ Footer คงที่ เนื้อหาตรงกลางเลื่อนแนวตั้งเมื่อพื้นที่ไม่พอ

## ตัวอย่างขั้นตอนใน AI Chat

```text
ผู้ใช้: แจ้งซ่อมเครื่องพิมพ์
AI: กรุณาเลือกหัวข้อและระบุรายละเอียด
ผู้ใช้: ระบบไฟฟ้า เครื่องพิมพ์เปิดไม่ติด
AI: ตรวจสอบข้อมูลก่อนส่ง: หัวข้อ ระบบไฟฟ้า / รายละเอียด เครื่องพิมพ์เปิดไม่ติด
                                  [ยกเลิก] [ยืนยันแจ้งซ่อม]

ผู้ใช้: เดือนนี้ใช้ค่าอะไหล่เท่าไร
AI: ต้นทุนอะไหล่งานซ่อมที่เสร็จในเดือนนี้ ... บาท (... งาน)
    ยอดนี้ยังไม่รวมค่าแรงหรือค่าบริการอื่น
    ต้องการส่งออกคำตอบเป็นรูปแบบใด?
    [PDF]  [รูปภาพ PNG]  [HTML]
    [ส่งอีเมล]

ผู้ใช้: ส่งอีเมล
AI: กรุณาระบุอีเมลผู้รับ
ผู้ใช้: user@example.com
AI: ส่งสรุปต้นทุนอะไหล่เดือนนี้ไปที่ user@example.com
    กรุณาตรวจสอบผู้รับและเนื้อหาก่อนส่ง
                                  [ยกเลิก] [ยืนยันส่งอีเมล]
```

ถ้าบริษัทบังคับแนบรูป AI จะแนะนำให้ไปหน้าจอแจ้งซ่อมปกติ ส่วนข้อมูลค่าใช้จ่ายและประวัติแสดงตามสิทธิ์และขอบเขตที่ได้รับ

## การแสดงและส่งออกคำตอบ

- AI แสดงคำตอบใน Chat ก่อน แล้วแสดงปุ่มส่งออกตามรูปแบบที่ความสามารถรองรับและ Company อนุญาต ผู้ใช้กดปุ่มที่ต้องการเพื่อสร้างไฟล์
- PDF เหมาะสำหรับพิมพ์หรือเก็บเป็นรายงาน; PNG เป็นภาพสรุป; HTML เปิดดูใน Browser และรองรับตารางหรือกราฟตามข้อมูลของความสามารถนั้น
- สร้างไฟล์ภายในองค์กร ตรวจ AI Chat, Company, Package, Permission และขอบเขตข้อมูลซ้ำขณะขอส่งออก หากสิทธิ์เปลี่ยนให้ปฏิเสธการสร้างไฟล์
- เนื้อหาที่ส่งออกต้องตรงกับข้อมูลที่ผู้ใช้มีสิทธิ์เห็น ระบุช่วงวันที่ วันที่สร้าง หน่วย และข้อจำกัดของยอด เช่น ต้นทุนอะไหล่ไม่รวมค่าแรงหรือค่าบริการอื่น
- หากสร้างไฟล์ไม่สำเร็จให้แจ้งข้อความและให้ลองใหม่ได้ โดยยังคงคำตอบใน Chat ไว้

## ส่งอีเมลจากคำตอบ

- แสดงปุ่ม `ส่งอีเมล` เฉพาะเมื่อ Company เปิดใช้สำหรับความสามารถนั้น และระบบมีบริการอีเมลพร้อมใช้งาน
- เมื่อผู้ใช้เลือกส่ง ให้ AI ขออีเมลผู้รับ ตรวจรูปแบบ แล้วแสดงผู้รับและสรุปเนื้อหาที่จะส่ง ผู้ใช้ต้องกด `ยืนยันส่งอีเมล` ก่อนส่งจริง หรือกดยกเลิกได้
- หากต้องการแนบไฟล์ ให้ผู้ใช้เลือกรูปแบบ PDF, PNG หรือ HTML จากรูปแบบที่ Company อนุญาตก่อนยืนยัน; หากไม่เลือกไฟล์ ให้ส่งข้อความสรุปในอีเมล
- ตรวจสถานะ AI Chat, สิทธิ์เมนู, Package และขอบเขตข้อมูลซ้ำก่อนส่ง และจำกัดเนื้อหาให้เท่าที่ผู้ใช้มีสิทธิ์เห็น
- หลังส่งให้แจ้งผลสำเร็จหรือสาเหตุที่ส่งไม่ได้อย่างเหมาะสม ผู้ใช้สามารถลองใหม่ได้ และป้องกันการกดยืนยันซ้ำจนส่งหลายฉบับ
- ใช้ค่าบริการอีเมลที่ผู้ดูแลระบบตั้งไว้ การส่งอีเมลออกนอกองค์กรขึ้นอยู่กับการตั้งค่าและการเชื่อมต่อของบริการอีเมลนั้น
