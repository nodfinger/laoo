# แบบร่างหน้าจอรูปแบบลำดับข้อมูล

สถานะ: ผู้ใช้อนุมัติแบบและกำหนด MenuCode `05004`, ScreenType `2` (UpdateOnly) แล้ว; เริ่มรองรับใบเสนอราคา `09003` แล้ว เอกสารชนิดอื่นยังต้องเชื่อมตัวออกเลขและทดสอบก่อนเปิด RunData

```text
┌─ รูปแบบลำดับข้อมูล  ☆ ───────────────────────────────┐
│                                          [บันทึก]    │
└───────────────────────────────────────────────────────┘
┌─ ค้นหา ──────────────────────────────────────────────┐
│ [ค้นหาชื่อหน้าจอ________] [ค้นหา] [ล้าง Filter]      │
│ [กลุ่มเมนู: ทั้งหมด ▾]                               │
└───────────────────────────────────────────────────────┘
┌─ รายการหน้าจอที่กำหนดการรันลำดับ ──────────────────┐
│ กลุ่มเมนู: ...                                       │
│ ชื่อหน้าจอ       Prefix    รูปแบบวันที่    จำนวนหลัก │
│ ...              [____]    [________▾]      [___]    │
│ ...              [____]    [________▾]      [___]    │
└───────────────────────────────────────────────────────┘
┌─ <  1  >   1–10 จาก ... ────────────────────────────┐
└───────────────────────────────────────────────────────┘
```

- แสดงหน้าจอเอกสารที่ `ScreenType = 4` และ `dbo.TDADMainMenu.RunData = 1` ที่เชื่อมการออกเลขแล้ว รวมทั้งใบแจ้งซ่อม `20001` ซึ่งผู้ใช้สั่งเพิ่มภายหลังและเป็น ScreenType 1 เดิม โดยจัดกลุ่มเมนูและตรวจสิทธิ์ ขอบเขตบริษัท และแพ็กเกจ; ค่า RunData เดิมของ ScreenType 1 ไม่เปลี่ยน และการรันรหัสข้อมูลหลักจะกำหนดภายหลัง
- หน้านี้เป็น UpdateOnly ไม่มีการเพิ่มหรือลบเมนู; ปุ่มบันทึกต้องมีสิทธิ์ EDIT
- Prefix, รูปแบบวันที่ และจำนวนหลักเป็นข้อเสนอเพื่อให้เห็นแบบ ยังไม่ได้กำหนดชนิด รูปแบบค่า หรือพฤติกรรมการออกเลขจริงจนกว่าจะยืนยัน
- จัดสี ตัวอักษร Card ช่องค้นหา ปุ่ม และการแบ่งหน้าตามมาตรฐานส่วนกลาง; จอแคบจัดข้อมูลให้ไม่ล้น
- การเปลี่ยนรูปแบบต้องไม่แก้เลขเอกสารเก่า และการออกเลขใหม่ต้องป้องกันเลขซ้ำเมื่อมีการบันทึกพร้อมกัน
- รูปแบบประกอบด้วย Prefix, สัญลักษณ์หลัง Prefix, ปี (ไม่ใช้/2/4 หลัก), เดือนและวัน (เลือกใช้แยกกัน แต่ละส่วน 2 หลัก), สัญลักษณ์ก่อนลำดับ และจำนวนหลักของลำดับ ค่าเริ่มต้นของแบบใหม่คือ 3 หลัก โดยเริ่มใช้หลังกดบันทึกเท่านั้น สัญลักษณ์รองรับ `-`, `_`, `/`, `.` ไม่เกิน 2 ตัวต่อช่อง

## ผลตรวจการออกเลขเดิม

- ใบเสนอราคา `09003` ใช้ `QT` ตามด้วยเลข 6 หลัก; ใบส่งของ `09006` ใช้ `DN` ตามด้วยเลข 6 หลัก ทั้งสองอ่านเลขเดิมภายใต้ transaction และ lock
- ใบรับจองสินค้า `09004`, ใบเสร็จรับเงินชั่วคราว `09005`, ใบกำกับภาษี `09007` และรับสินค้าเข้าคลัง `08005` มีตัวออกเลขแยกในแต่ละ Controller เช่นกัน
- เบิกจ่ายอะไหล่ `08003` ใช้เวลาปัจจุบันเป็นส่วนหนึ่งของเลขเอกสาร ไม่ใช่เลขลำดับแบบเดียวกัน
- นอกเหนือจากใบเสนอราคา ตัวออกเลขเหล่านี้ยังไม่อ่านค่าจากส่วนกลาง จึงต้องเชื่อมต่อและทดสอบแต่ละประเภทก่อนเปิด RunData
- ใบเสนอราคา `09003` เชื่อมการอ่านค่ารายบริษัทแล้ว; ถ้าไม่มีค่าตั้งจะใช้ `QT` และเลข 6 หลักเหมือนเดิม ค้นเลขเดิมใน transaction และป้องกันเลขซ้ำด้วยข้อกำหนด unique เดิมในฐานข้อมูล
- ใบแจ้งซ่อม `20001` ใช้รูปแบบร่วมกันทั้งการแจ้งเอง แจ้งแทน AI และการส่งต่อจากงานตรวจ; หากยังไม่ได้บันทึกค่าจะใช้ `SR` ตามด้วยวันที่ `yyyyMMdd` และเลข 6 หลักตามเดิม ค่าเริ่มต้นที่เสนอในหน้าตั้งค่าใช้ 3 หลักและมีผลเมื่อบันทึก
