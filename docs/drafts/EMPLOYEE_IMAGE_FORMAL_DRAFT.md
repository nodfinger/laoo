กติกา Draft:

- รูปทางการแก้ไขได้จากหน้า Employee ตาม Permission
- รูปต้องตรวจชนิดไฟล์และขนาดไม่เกิน 100 KB ก่อนส่ง API
- เมื่อ User เลือกรูป ต้องแสดง Preview ใน Card ทันทีโดยยังไม่ต้องบันทึก
- ถ้ารูปเกิน 100 KB ระบบต้องย่อ/บีบอัดอัตโนมัติให้เหลือไม่เกิน 100 KB
- แสดงหมายเหตุด้วยตัวอักษรขนาดเล็กใต้ Card: `รูปไม่เกิน 100 KB ระบบจะลดขนาดให้อัตโนมัติ`
- `FORMAL` มีได้ 1 รูปต่อ Employee
- รูป Profile ของพนักงานจะอยู่ใน Action/หน้าสำหรับพนักงานอีก Flow หนึ่ง
