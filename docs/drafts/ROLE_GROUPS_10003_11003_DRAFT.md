# Draft: กลุ่มสิทธิ

สถานะ: Draft ลายเส้นเท่านั้น — ยังไม่สร้างหน้าจอจริงและยังไม่เชื่อม API

เมนูในขอบเขต:

- `10003` — Customer / `companyRoleGroups`
- `11003` — Partner / `partnerRoleGroups`

> หมายเหตุ: ต้องยืนยัน `MenuName` และ `ScreenType` จาก `dbo.TDADMainMenu` ก่อนเริ่ม Code อีกครั้ง เนื่องจากการอ่านฐานข้อมูลรอบนี้ติดปัญหา SSL จากเครื่องมือเชื่อมต่อ

## 1. List — กลุ่มสิทธิ

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ Sidebar │ Top Bar: Logo                                      User / Project   │
│         ├─────────────────────────────────────────────────────────────────────┤
│         │ กลุ่มสิทธิ์                                      [ + เพิ่ม ]         │
│         │                                                                      │
│         │ [ 🔍 ค้นหาชื่อกลุ่มสิทธิ์                         ➜ ] [ล้าง Filter] │
│         │                                                                      │
│         │ ┌──────┬──────────────┬──────────────────────┬──────────────┬─────┐ │
│         │ │  ID  │ Action       │ รหัสกลุ่มสิทธิ์      │ ชื่อกลุ่ม    │สถานะ│ │
│         │ ├──────┼──────────────┼──────────────────────┼──────────────┼─────┤ │
│         │ │  1   │ ✎  🗑         │ ADMIN                │ ผู้ดูแลระบบ  │ เปิด│ │
│         │ │  2   │ ✎  🗑         │ OPERATOR             │ ผู้ปฏิบัติงาน│ เปิด│ │
│         │ │  3   │ ✎  🗑         │ VIEWER               │ ผู้ดูข้อมูล  │ ปิด │ │
│         │ └──────┴──────────────┴──────────────────────┴──────────────┴─────┘ │
│         │                                                                      │
│         │ ก่อนหน้า   [1]  2  3   ถัดไป        แสดง 1-10 จาก 25 รายการ        │
└─────────┴─────────────────────────────────────────────────────────────────────┘
```

กติกาที่แสดงในแบบร่าง:

- Column 1 เป็น `ID` แบบเลขลำดับหน้า ไม่ใช่ Database Key
- Column 2 เป็น `Action`; แสดง Edit/Delete ตาม Permission ของผู้ Login
- ปุ่ม `+ เพิ่ม`, Search, ล้าง Filter, Refresh และ Pagination อยู่ตามมาตรฐานกลาง
- ตารางใช้พื้นที่ Content เต็ม และใช้เส้นแบ่งแถว

## 4. ความสัมพันธ์ของสองเมนู

```text
10003 Customer  ──┐
                   ├─ ใช้ Layout และ Flow เดียวกัน
11003 Partner   ──┘
                   └─ ต่างกันที่ Scope / Permission Context / ข้อมูลที่มองเห็น
```

ก่อนขึ้น Code ต้องยืนยันเพิ่ม: ฟิลด์จริงของ Role Group, ชุด Permission ของ Action, Flow หลัง Save และกติกาว่าแก้ไข/ลบ Role ที่ถูกใช้งานอยู่ได้หรือไม่
