# แบบร่าง: กำหนดสิทธิ์ใช้ความสามารถ AI ตามกลุ่มสิทธิ์

## สิทธิ์ระดับย่อย

เพิ่มรายการ `ระบบ AI > จัดการความสามารถ AI > กำหนดสิทธิ` สำหรับกำหนดว่าใครจัดการสิทธิ์ของความสามารถได้ การกำหนดจุดสิทธิ์นี้ใช้ระบบสิทธิ์ระดับย่อยเดิม

## หน้าจัดการความสามารถ AI

ในคอลัมน์ Action และมุมมอง Card เพิ่มปุ่ม **กำหนดสิทธิ** ต่อจากปุ่มแก้ไข แสดงตามสิทธิ์ของผู้ใช้ที่เข้าสู่ระบบ

## แบบร่าง Popup

```text
┌────────────────────────────────────────────────────────────┐
│ 🔐 กำหนดสิทธิ์ความสามารถ AI > แจ้งงานซ่อมใหม่            │
├────────────────────────────────────────────────────────────┤
│ [ 🔍 ค้นหาชื่อกลุ่มสิทธิ์                              ]   │
├────────────────────────────────────────────────────────────┤
│ อนุญาต │ กลุ่มสิทธิ์                                      │
├────────┼───────────────────────────────────────────────────┤
│ [✓]    │ admin                                            │
│ [✓]    │ it-user                                          │
│ [ ]    │ ตัวอย่างกลุ่มอื่น                                │
├────────┴───────────────────────────────────────────────────┤
│ [‹] [1] [›]  1–3 จาก 3                                   │
├────────────────────────────────────────────────────────────┤
│                                  [ยกเลิก]  [บันทึก]      │
└────────────────────────────────────────────────────────────┘
```

- รายชื่อและค่าที่เลือกในภาพเป็นตัวอย่าง จะแสดงเฉพาะกลุ่มของบริษัทผู้ใช้ โดยรองรับค้นหา เลื่อน และแบ่งหน้าตามมาตรฐาน
- บันทึกการอนุญาตแยกตามบริษัท กลุ่มสิทธิ์ และความสามารถ; สิทธิ์จัดการหน้าจอนี้ไม่เท่ากับสิทธิ์เรียกใช้งานความสามารถ
- หากยังไม่เคยกำหนดสิทธิ์สำหรับความสามารถนั้น ให้รักษาการเข้าถึงเดิมจนกว่าผู้ดูแลบันทึก; หลังบันทึกให้ตรวจสิทธิ์กลุ่มร่วมกับแพ็กเกจ สิทธิ์เมนู และขอบเขตข้อมูลทุกครั้งที่ Backend
- หากสมาชิกอยู่หลายกลุ่ม ให้ใช้สิทธิ์เมื่ออย่างน้อยหนึ่งกลุ่มได้รับอนุญาต ผู้ดูแลบริษัทคงสิทธิ์ตามกติกาเดิม
- การยกเลิกและค้นหาไม่เปลี่ยนข้อมูล กดบันทึกจึงบันทึกรายการที่เลือกทั้งหมดในครั้งเดียว
