- ตำแหน่งหนึ่งตำแหน่งห้ามปรากฏซ้ำข้ามลำดับ และตรวจซ้ำใน Backend ก่อนบันทึก
- เพิ่มลำดับและตำแหน่งในแต่ละลำดับได้หลายรายการ มีตัวควบคุมเลื่อนลำดับ
- กรณีมีหลายตำแหน่ง ให้เลือกอนุมัติอย่างน้อยหนึ่งตำแหน่ง หรืออนุมัติครบทุกตำแหน่ง
- ค่าบันทึกแยกตามบริษัท ตรวจสิทธิ์การบริหารทั้งที่หน้าจอและ API
- ไม่เปลี่ยนกระบวนการอนุมัติเอกสารที่ใช้อยู่ จนกว่าจะระบุเมนูเอกสารที่จะนำรูปแบบไปใช้และทดสอบเส้นทางนั้น
- จำนวนระดับนับจากระดับผู้บันทึกขึ้นไปตามลำดับของบริษัท; ตำแหน่งที่ว่างหรือตรงกับผู้บันทึกให้ข้ามเฉพาะตำแหน่งนั้นและส่งให้ตำแหน่งที่เหลือในลำดับเดียวกัน
- หน่วยงานเลือกได้ระหว่างทุกหน่วยงาน แผนกเดียวกัน และฝ่ายเดียวกัน
- ใช้มาตรฐานสีตามผู้ใช้ Caption สีดำ Card/ช่องกรอก/ปุ่มมุม 4 px และเส้นแบ่ง 0.6 px
