# แบบร่าง: กำหนดค่าระบบเบิกค่าเดินทาง

```text
ระบบของฉัน
├─ ผู้ดูแลระบบ
├─ การใช้งานส่วนกลาง
│  └─ คำขอจัดซื้อ
└─ ระบบเบิกค่าเดินทาง
   ├─ กำหนดค่าระบบ                  ScreenType 2 (เมนูใหม่)
   └─ เบิกค่าเดินทาง                  MenuCode 66001, ScreenType 4 (เมนูเดิม)
```

```text
┌────────────────────────────────────────────────────────────────┐
│ ⚙ กำหนดค่าระบบ                                           ☆ │
└────────────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────────────┐
│ อัตราค่าน้ำมัน/กม./ประเภทรถ                                  │
├────────────────────────────────────────────────────────────────┤
│ ประเภทรถ (จาก MasterGroup 009)     │ เบิกได้ต่อ กม. (บาท)    │
│ รถยนต์                             │ [                  ]     │
│ รถจักรยานยนต์                      │ [                  ]     │
│ ...                                │ [                  ]     │
│                                               [ บันทึก ]     │
└────────────────────────────────────────────────────────────────┘
```

- ตั้งค่าต่อบริษัทและประเภทรถ แสดงรายการจากข้อมูลประเภทรถที่บริษัทใช้งานได้ และบันทึกอัตราของตารางนี้ด้วยปุ่มของส่วนนี้โดยเฉพาะ
- เมนูเบิกค่าเดินทางเดิมคง MenuCode 66001 และสิทธิ์ที่ผูกไว้ การย้ายเปลี่ยนกลุ่มเมนู ไม่ลบข้อมูลเดิม
- สี ไอคอน ขนาดตัวอักษร ระยะห่าง Card และการแจ้งผลอิง User Style และมาตรฐานส่วนกลาง
