# แบบร่างกำหนดการแสดงและจัดเรียงข้อมูลรายผู้ใช้

สถานะ: แบบร่างหน้าจอ ยังไม่เชื่อม API และยังไม่เปลี่ยนฐานข้อมูล

เปิดจากปุ่ม **กำหนดแสดง/จัดเรียงข้อมูล** ในข้อมูลส่วนตัว โดยใช้เมนูที่ผู้เข้าสู่ระบบมีสิทธิ์เห็นและบริษัทเปิดใช้งาน

```text
┌─ กำหนดแสดง/จัดเรียงข้อมูล ─────────────────────────────┐
│ ค้นหาระบบ กลุ่มเมนู หรือหน้าจอ                         │
├──────────────────────────────────────────────────────────┤
│ ระบบแจ้งซ่อม                                            │
│   บริการตนเอง                                           │
│     แจ้งซ่อม / ขอใช้บริการ              [กำหนดค่า]      │
│ ระบบบริหารสต๊อก                                         │
│   ข้อมูลสินค้า                           [กำหนดค่า]      │
├──────────────────────────────────────────────────────────┤
│ <  1  >   1–10 จาก 30                         [ปิด]     │
└──────────────────────────────────────────────────────────┘

┌─ กำหนดคอลัมน์ > ชื่อหน้าจอ ───────────────────────────┐
│ ตำแหน่ง Action    (• ซ้าย)  (  ขวา)                     │
│                                                          │
│ แสดง  ชื่อข้อมูล                         เลื่อนลำดับ      │
│ [✓]   ชื่อ                               [↑] [↓]        │
│ [✓]   สถานะ                             [↑] [↓]        │
│ [ ]   วันที่                             [↑] [↓]        │
│                                                          │
│       [คืนค่ามาตรฐาน]   [ยกเลิก]   [บันทึก]             │
└──────────────────────────────────────────────────────────┘
```

- อ่านชื่อระบบและเมนูจาก Navigation API ตาม session และแพ็กเกจ ไม่รับสิทธิ์จาก client
- ค่าเริ่มต้นและการคืนค่ามาจากนิยามส่วนกลางของหน้าจอ ไม่ลบข้อมูลธุรกิจ
- ใช้รายการฟิลด์ที่แต่ละหน้าจออนุญาตให้แสดงจริงและตรวจสิทธิ์เสมอ ไม่เปิดเผยทุกคอลัมน์ดิบจาก SQL เพราะบางฟิลด์เป็นข้อมูลลับหรือฟิลด์ภายใน
- บันทึกแยกเจ้าของและหน้าจอ; เมื่อเพิ่ม/ลบฟิลด์ในรุ่นใหม่ให้รวมค่าเริ่มต้นใหม่และข้ามฟิลด์ที่ไม่รู้จัก
- List และ Card ใช้ลำดับและการแสดงเดียวกันเมื่อหน้าจอรองรับ; Action ยังตรวจสิทธิ์เดิมและข้อมูลที่จำเป็นต่อการทำงานไม่หายไปจากระบบ
- หน้าจอที่ยังไม่มีนิยามฟิลด์ส่วนกลางจะแจ้งว่าอยู่ระหว่างรองรับ แทนการอ้างว่าตั้งค่าแล้วมีผล
- ใช้ Card, Pagination, สี User Style และขนาดตัวอักษรตามมาตรฐาน และรองรับหน้าจอแคบ
