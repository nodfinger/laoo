# แบบร่าง: ค่าเดินทางระหว่างจุดเหมาจ่าย

เมนูอยู่ภายใต้ **ระบบของฉัน > ระบบเบิกค่าเดินทาง** เป็นหน้าจอ ScreenType 1 แยกข้อมูลตามบริษัท

```text
┌─────────────────────────────────────────────────────────────────────┐
│ ไอคอน ค่าเดินทางระหว่างจุดเหมาจ่าย ☆              [List/Card] [+ เพิ่ม] │
└─────────────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────────────┐
│ [ค้นหาต้นทาง หรือปลายทาง] [ค้นหา] [ล้าง Filter]                    │
└─────────────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────────────┐
│ ID │ Action: แก้ ลบ ประเภทรถ │ สถานที่ต้นทาง │ สถานที่ปลายทาง │ ระยะทาง กม. │
│ 1  │ แก้ ลบ ประเภทรถ         │ พระราม 2      │ โรงงานอัมพวา   │ 150         │
└─────────────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────────────┐
│ [ก่อนหน้า] [1] [ถัดไป] รายการ                                      │
└─────────────────────────────────────────────────────────────────────┘
```

เพิ่ม/แก้ไขเป็น Popup ตามมาตรฐาน เพราะมีไม่เกิน 10 ช่อง:

```text
┌──────────────────────────────────────────────────┐
│ ✎ ค่าเดินทางระหว่างจุดเหมาจ่าย > เพิ่ม           │
├──────────────────────────────────────────────────┤
│ [สถานที่ต้นทาง *                               ] │
│ [สถานที่ปลายทาง *                             ] │
│ [ระยะทาง (กม.) *                              ] │
├──────────────────────────────────────────────────┤
│                               [ยกเลิก] [บันทึก] │
└──────────────────────────────────────────────────┘
```

ปุ่มประเภทรถในแต่ละรายการเปิด Popup แสดงประเภทรถจาก MasterGroup 009 พร้อมช่องกรอกจำนวนเงินที่เบิกได้สำหรับเส้นทางนั้น และปุ่มบันทึกตามสิทธิ์ของผู้ใช้ แต่ละบริษัทมีค่าแยกกัน รายการที่ยังไม่ได้กำหนดจำนวนเงินให้แสดงช่องว่าง ไม่ถือว่าเป็นศูนย์โดยอัตโนมัติ

การปรับโครงสร้างต้องย้ายข้อมูลเดิมอย่างปลอดภัย: เส้นทางหนึ่งมีรายการจำนวนเงินหลายประเภทรถได้ ตรวจข้อมูลซ้ำหรือขัดแย้งก่อนรวมรายการ และรักษาจำนวนเงินเดิมทั้งหมด ห้ามเลือกค่าหนึ่งทับอีกค่าโดยอัตโนมัติ

รองรับ List/Card, ค้นหา, แบ่งหน้า และตรวจสิทธิ์ VIEW/CREATE/EDIT/DELETE ตามบริษัทและแพ็กเกจ สีและตัวอักษรตาม User Style โดยรายการจากภาพเป็นตัวอย่าง ไม่เพิ่มข้อมูลตัวอย่างลงฐานจริง
