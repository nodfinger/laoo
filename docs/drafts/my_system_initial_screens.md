# แบบร่างระบบของฉัน

ระบบเปิดหรือปิดแยกตามบริษัทผ่านแพ็กเกจระบบ และเริ่มต้นปิดจนกว่าผู้ดูแลเปิดใช้

## เมนู

```text
ระบบของฉัน
├─ ผู้ดูแลระบบ
│  ├─ กำหนดค่าระบบของฉัน          ScreenType 2
│  └─ ตรวจสอบข้อมูล API SAP-PMS    ScreenType 3
└─ การใช้งานส่วนกลาง
   ├─ เบิกค่าเดินทาง                 ScreenType 4
   └─ คำขอจัดซื้อ                   ScreenType 4
```

กำหนดรหัสเมนูอัตโนมัติ โดยตรวจรหัสว่างและบันทึกใน transaction ก่อนสร้าง หากรหัสถูกใช้ระหว่างดำเนินการให้ยกเลิกและแจ้งข้อผิดพลาด

## รูปแบบหน้าจอเริ่มต้นทั้งสี่

```text
┌───────────────────────────────────────────────────────────┐
│ ไอคอน   ชื่อหน้าจอจากฐานข้อมูล                    ☆      │
└───────────────────────────────────────────────────────────┘
┌───────────────────────────────────────────────────────────┐
│                                                           │
│                    หน้าจออยู่ระหว่างพัฒนา                 │
│                                                           │
└───────────────────────────────────────────────────────────┘
```

Card ระยะห่าง ตัวอักษรและสีตามมาตรฐานและ User Style หน้าจอเป็นเพียงพื้นที่ว่าง ไม่มีฟอร์ม เรียก SAP สร้างเอกสาร หรือบันทึกข้อมูลธุรกิจ จนกว่าจะกำหนดรายละเอียดและพัฒนาขั้นถัดไป

Backend และเมนูต้องตรวจแพ็กเกจรายบริษัทและสิทธิ์เข้าหน้าจอ ไม่เปิดสิทธิ์ให้ผู้ใช้โดยอัตโนมัติ
