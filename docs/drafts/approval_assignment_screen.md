# แบบร่างหน้ากำหนดการอนุมัติ

- แสดงเฉพาะเมนูที่ `TDADMainMenu.RequiresApproval = 1` และบริษัทเปิดใช้ระบบ/แพ็กเกจที่เกี่ยวข้อง
- เงื่อนไขแสดงชื่อรูปแบบการอนุมัติที่บริษัทกำหนดให้เมนูนั้น; หากยังไม่มีให้แสดง “ยังไม่กำหนด”
- ScreenType 3 ใช้สิทธิ์แสดงหน้าจอ และกำหนดรูปแบบผ่านสิทธิ์บริหารที่ตรวจฝั่ง Backend เพิ่มเติม
- ตั้งค่าแยกบริษัท ไม่อนุญาตพิมพ์ ส่งออก หรือกำหนดแสดง/จัดเรียงคอลัมน์รายผู้ใช้
- ใช้สีและขนาดตามผู้ใช้ Table อยู่ใน Card เว้นขอบ 10px เส้นแบ่ง 0.6px ปุ่มแบ่งหน้าอยู่ Card ล่างสุด
- หน้าจอใช้กำหนดความสัมพันธ์เมนูกับรูปแบบ ยังไม่อ้างว่าการส่งอนุมัติเอกสารจริงเชื่อมแล้ว
