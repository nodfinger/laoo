# แบบร่าง: กำหนดค่าระบบ AI

สถานะ: แบบร่าง เตรียมย้ายการตั้งค่า AI Chat จากหน้าจัดการความสามารถ AI ไปเป็นเมนูใหม่ในระบบ AI โดยใช้ ScreenType 2 (UpdateOnly) รอ MenuCode และการตรวจรหัสในฐานข้อมูล

```text
┌──────────────────────────────────────────────────────────────┐
│ 🤖  กำหนดค่าระบบ AI   ☆                          [บันทึก] │
└──────────────────────────────────────────────────────────────┘
┌─ ข้อมูล AI Chat ─────────────────────────────────────────────┐
│ ชื่อ AI Chat                         คำเรียกแทนตัวเอง        │
│ [____________________________]       [____________________]  │
│ รูปแบบข้อความต้อนรับ                                         │
│ [ทักทายตามช่วงเวลาและชื่อเล่น                         ▾]     │
└──────────────────────────────────────────────────────────────┘
┌─ ช่วงเวลาและข้อความทักทาย ──────────────────────────────────┐
│ ช่วงเวลา       เริ่ม       สิ้นสุด      ข้อความทักทาย        │
│ เช้า           [__:__]     [__:__]      [________________]   │
│ สาย            [__:__]     [__:__]      [________________]   │
│ บ่าย           [__:__]     [__:__]      [________________]   │
│ เย็น           [__:__]     [__:__]      [________________]   │
│ ค่ำ            [__:__]     [__:__]      [________________]   │
└──────────────────────────────────────────────────────────────┘
┌─ รูปภาพใน Chat ──────────────────────────────────────────────┐
│ แสดงรูปผู้ใช้งาน                                       [เปิด]│
│ แสดงรูป AI                                             [เปิด]│
│ [รูป AI ปัจจุบัน]  [เลือกรูป AI]                             │
└──────────────────────────────────────────────────────────────┘
```

- หน้าจอเต็มแบบ UpdateOnly; Caption อ่านจากเมนูในฐานข้อมูล ปุ่มบันทึกใช้สิทธิ์ EDIT และใช้สีตาม User Style
- ย้าย UI เดิม ไม่ลบค่าที่ตั้งไว้หรือรูปเดิม; คง Validation และตัวอัปเดตหน้าต่าง Chat เดิม
- ตรวจแพ็กเกจระบบ AI และสิทธิ์ VIEW/EDIT ของเมนูใหม่ทั้ง UI และ API แยกจากเมนูจัดการความสามารถ AI
- บัญชีเดิมที่มีสิทธิ์ตั้งค่า AI ต้องตรวจและวางแผนรักษาสิทธิ์ก่อนเปลี่ยน ไม่ขยายสิทธิ์ให้ผู้ใช้อื่นโดยอัตโนมัติ
- จอแคบจัดแต่ละช่วงเวลาเป็นหลายบรรทัดโดยไม่ตัดข้อมูล ขนาด สี ระยะ Card และปุ่มอ้างอิงมาตรฐานส่วนกลาง
