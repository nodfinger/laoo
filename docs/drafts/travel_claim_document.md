# แบบร่าง: เบิกค่าเดินทาง

เมนูเดิม `66001` เบิกค่าเดินทาง (`ScreenType 4`) ภายใต้ระบบเบิกค่าเดินทาง แบบร่างนี้ยังไม่สร้างเอกสารหรือแก้ฐานข้อมูล

```text
┌─ เบิกค่าเดินทาง ──────────────────────────────── [List/Card] [+ เพิ่ม] ─┐
├─ [ค้นหาเลขที่/ต้นทาง/ปลายทาง] [ค้นหา] [ล้าง Filter] [สถานะ: ทั้งหมด] ─┤
├─ รายการเอกสาร: ID | Action | เลขที่ | วันที่ | ต้นทาง | ปลายทาง | ยอดรวม ┤
└─ [ก่อนหน้า] [หน้า] [ถัดไป]  จำนวนรายการ ──────────────────────────────┘

┌─ เบิกค่าเดินทาง > เพิ่ม/แก้ไข ────────────────── [ยกเลิก] [บันทึก] ──┐
├─ ข้อมูลการเดินทาง ───────────────────────────────────────────────────┤
│ เลขที่เอกสาร [ระบบสร้าง]   วันที่บันทึก [วันที่]                     │
│ เดินทางระหว่างสาขา [เลือก]   ต้นทาง [     ]   ปลายทาง [     ]       │
│ วัตถุประสงค์ปฏิบัติงาน [                                        ]    │
│ สถานที่ปฏิบัติงาน      [                                        ]    │
│ Link Map (ถ้ามี)       [                                        ]    │
│ ระยะทาง/วัน [ ]  วันที่เริ่ม [ ]  วันที่สิ้นสุด [ ]  จำนวนวัน [ ]   │
│ ประเภทรถ [เลือก]  ทะเบียนรถ [ ]  ค่าน้ำมัน/กม. [ ]  รวมค่าน้ำมัน [ ] │
├─ ข้อมูลการเบิกจ่าย ──────────────────────────────────────────────────┤
│ ค่าทางด่วน [ ]  ค่าที่จอดรถ [ ]  ค่ายานพาหนะสาธารณะ [ ]             │
│ ค่าที่พัก/คืน [ ]  จำนวนคืน [ ]  รวมค่าที่พัก [ ]                   │
│ ยอดเบิกรวม [คำนวณ]                                                  │
├─ ไฟล์ประกอบ ─────────────────────────────── [เลือกหลายไฟล์] ────────┤
│ รายชื่อ/ตัวอย่างรูปและ PDF พร้อมปุ่มลบแต่ละไฟล์                    │
└──────────────────────────────────────────────────────────────────────┘
```

- ใช้สีและตัวอักษรตาม User Style, Card และปุ่มตามมาตรฐาน; วันที่แสดง dd/MM/yyyy
- จำนวนวันเดินทางคิดรวมวันเริ่มและวันสิ้นสุด หากวันสิ้นสุดก่อนวันเริ่มให้แจ้งข้อผิดพลาด
- ยอดรวมเป็นผลบวกค่าน้ำมัน ค่าทางด่วน ค่าที่จอดรถ ค่ายานพาหนะสาธารณะและค่าที่พัก โดย Backend ตรวจและคำนวณซ้ำ
- อ่านรายการประเภทรถและอัตราต่อกม. จากการตั้งค่าของบริษัท ใช้ราคาเหมาจ่ายที่ตั้งไว้สำหรับเส้นทางและประเภทรถก่อน หากไม่พบจึงใช้ระยะทางต่อวัน × จำนวนวันเดินทาง × อัตราต่อกิโลเมตร
- กำหนดความสัมพันธ์ตำแหน่งงานกับระดับตำแหน่งแยกตามบริษัท แล้วอ่านอัตราค่าที่พักจากระดับตำแหน่งของพนักงาน คิดเป็นอัตราต่อคืน × จำนวนคืน
- รองรับผู้ใช้กำหนดการแสดงและลำดับคอลัมน์ List/Card ด้วยตนเอง
- แนบได้หลายไฟล์ทั้งรูปและ PDF ตรวจชนิด ขนาด สิทธิ์ และบริษัทจาก Backend; กำหนดข้อจำกัดที่เหมาะสมตามโครงสร้างโครงการก่อนพัฒนา
- ตรวจสิทธิ์ราย Action แพ็กเกจและขอบเขตบริษัทที่ Backend พร้อมใช้ระบบเลขเอกสารส่วนกลาง; ไม่กำหนดวงเงินหรือสถานะอนุมัติโดยเดา
- พ่อยืนยัน Layout และเงื่อนไขการคิดค่าแล้ว
