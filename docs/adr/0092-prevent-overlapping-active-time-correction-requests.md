# ห้ามคำขอแก้เวลาที่กำลังดำเนินการซ้ำจุดเดียวกัน

ระบบอนุญาต Active Time Correction Request ได้เพียงหนึ่งรายการต่อ Employee, Work Date, Attendance Session Rule และฝั่งเข้าออกเดียวกัน หากมีคำขอเดิมอยู่ Employee ต้องแก้หรือยกเลิกรายการนั้นก่อนส่งใหม่ คำขอที่ถูกปฏิเสธ ยกเลิก หรือดำเนินการเสร็จแล้วไม่ขวางคำขอใหม่ เหตุผลคือคำขอพร้อมกันที่เปลี่ยนจุดเวลาเดียวกันอาจได้รับอนุมัติคนละลำดับและสร้าง Time Adjustment ขัดกันหรือซ้ำกัน
