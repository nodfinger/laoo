# เก็บเหตุการณ์เวลาต้นฉบับและแยกรายการปรับเวลา

LAOO_TIME เก็บ Attendance Event ต้นฉบับไว้โดยไม่เขียนทับ และใช้ Time Adjustment ที่ระบุเหตุผลกับผู้ดำเนินการเมื่อต้องแก้เวลา เหตุผลคือระบบต้องรองรับแหล่งบันทึกเวลาหลายชนิดในอนาคตและตรวจสอบย้อนหลังได้ แม้ต้องเก็บทั้งหลักฐานเดิมและค่าที่ใช้คำนวณแทนการรักษาเพียงค่าล่าสุด
