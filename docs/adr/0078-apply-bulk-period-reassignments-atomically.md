# บันทึกการย้าย Period Scheme แบบกลุ่มทั้งชุด

Bulk Period Scheme Reassignment ต้องตรวจ Employee ทุกคนก่อนบันทึก และดำเนินการเป็น Transaction เดียว หากมี Assignment ซ้อน กระทบ Period ที่ Finalized โดยยังไม่เปิด หรือผิดกติกากับ Employee คนใด ต้องไม่ย้ายทั้งชุดและแสดงรายชื่อพร้อมสาเหตุให้แก้ก่อนยืนยันใหม่ เหตุผลคือการย้ายสำเร็จเพียงบางส่วนทำให้กลุ่มธุรกิจเดียวกันกระจายไปคนละ Scheme โดยผู้ใช้ไม่ตั้งใจ และยากต่อการตรวจว่ารายงานใดครอบคลุมใครบ้าง
