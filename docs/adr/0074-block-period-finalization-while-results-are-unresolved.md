# ห้ามปิดงวดขณะมีผลเวลาที่ยังสรุปไม่ได้

Attendance Period ห้าม Finalize หาก Attendance Period Membership ใดมี Unresolved Attendance Result และระบบไม่มีปุ่มข้ามแบบเงียบ ๆ ผู้มี Permission ต้องแก้ให้เป็นผลที่อธิบายได้ เช่น อนุมัติ Time Adjustment หรือบันทึก Explained Absence ก่อนจึงปิดงวด เหตุผลคือ Final Attendance Report ต้องประกอบด้วยผลที่มีความหมายแน่นอน การข้ามรายการค้างจะซ่อนความไม่ครบถ้วนและทำให้รายงานทางการไม่สามารถตรวจสอบย้อนกลับได้
