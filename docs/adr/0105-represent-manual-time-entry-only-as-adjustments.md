# เก็บเวลาที่คนคีย์เป็น Time Adjustment เท่านั้น

เวลาที่เจ้าหน้าที่คีย์เพราะ Employee ลืมลงเวลา เครื่องเสีย หรือเหตุผลอื่นต้องสร้างเป็น Time Adjustment พร้อม Time Adjustment Reason หลักฐาน ผู้ดำเนินการ และ Approval Workflow ห้ามส่งผ่าน Canonical Attendance Import Contract เพื่อสร้าง Attendance Event Attendance Event สงวนสำหรับหลักฐานจากแหล่งบันทึกจริง เหตุผลคือข้อมูลคีย์มือเป็นการรับรองหรือแก้ผล ไม่ใช่หลักฐานต้นฉบับจากเครื่อง และต้องตรวจย้อนกลับได้ว่าใครเป็นผู้กำหนดเวลาแทน
