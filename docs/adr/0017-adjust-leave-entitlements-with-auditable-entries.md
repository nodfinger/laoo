# ปรับสิทธิ์ลาด้วยรายการที่ตรวจสอบย้อนหลังได้

LAOO_TIME อนุญาตให้ผู้มี Permission ปรับ Leave Entitlement เพิ่มหรือลดผ่าน Leave Entitlement Adjustment ที่เก็บเหตุผล ผู้ดำเนินการ และเวลาทำรายการ โดยไม่เขียนทับสิทธิ์ที่เกิดจาก Leave Policy เหตุผลคือองค์กรต้องแก้ข้อยกเว้นและข้อมูลผิดพลาดได้ แต่ยอดคงเหลือต้องอธิบายย้อนกลับถึงสิทธิ์ตั้งต้น การใช้สิทธิ์ และรายการปรับทุกครั้ง
