# Use Project, Menu Group, and Main Menu as three navigation levels

LAOO ใช้ `Project → Menu Group → Main Menu` เป็นโครงสร้าง Navigation กลาง โดยคง `LAOO` เป็น Core Project, ใช้ `LAOO_MEETING` สำหรับระบบห้องประชุม และแยก `LAOO_SERVICE` สำหรับระบบแจ้งซ่อม การตัดสินใจนี้ป้องกันเมนูส่วนกลางซ้ำเมื่อ Company ซื้อหลายระบบ และแยก Company Project Entitlement ออกจาก User Project Access เพื่อให้ Partner เปิดระบบโดยไม่ข้ามสิทธิ์ผู้ใช้
