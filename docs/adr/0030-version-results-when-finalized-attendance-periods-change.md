# ปิดงวดเวลาและสร้างผลเวอร์ชันใหม่เมื่อแก้ย้อนหลัง

LAOO_TIME แบ่ง Attendance Period เป็นงวดเปิดและงวดปิด งวดเปิดคำนวณผลใหม่ได้อัตโนมัติ แต่งวดปิดห้ามเปลี่ยนเงียบ ๆ ผู้มี Permission ต้องเปิดแก้พร้อมเหตุผลและปิดเป็น Attendance Result เวอร์ชันใหม่ ส่วน Attendance Event ที่เข้าหลังปิดงวดเก็บเป็น Late Period Event รอตรวจสอบ เหตุผลคือข้อมูลย้อนหลังต้องแก้ข้อผิดพลาดได้โดยยังรักษาผลที่เคยรับรองและอธิบายความแตกต่างระหว่างแต่ละรอบได้
