# ใช้รหัสลงเวลาที่เครื่องหนึ่งรหัสต่อพนักงาน

LAOO_TIME ใช้ Attendance Device Code หนึ่งค่าปัจจุบันต่อ Employee ซึ่งต้องไม่ซ้ำภายใน Company และใช้รหัสเดียวกันกับทุกอุปกรณ์หรือวิธีลงเวลา ข้อมูลนี้อยู่ใน Time Management Project โดยอ้าง Employee กลาง และเมื่อเปลี่ยนรหัสต้องเก็บประวัติ เหตุผลคือหน้าตั้งค่าพนักงานควรมีรหัสจับคู่เพียงช่องเดียว ขณะที่การเก็บประวัติป้องกันไม่ให้การนำเข้าหรือคำนวณย้อนหลังจับคู่กับ Employee ผิดคน
