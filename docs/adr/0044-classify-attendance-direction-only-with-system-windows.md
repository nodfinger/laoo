# ใช้ช่วงเวลาของระบบกำหนดทิศทางเข้าออก

LAOO_TIME กำหนด Calculated Attendance Direction จาก Attendance Classification Window ของระบบเท่านั้นและไม่ใช้ค่า IN/OUT จากอุปกรณ์ในการคำนวณ แม้ยังเก็บข้อมูลต้นทางที่อุปกรณ์ส่งมาได้ เหตุผลคือแต่ละอุปกรณ์มีรูปแบบและความน่าเชื่อถือของประเภท Event ต่างกัน ขณะที่ช่วงเวลาที่ Company กำหนดเป็นกฎเดียวที่อธิบายและควบคุมผลได้สม่ำเสมอ
