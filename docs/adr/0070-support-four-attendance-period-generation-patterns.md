# รองรับสี่รูปแบบการสร้างงวดเวลา

Attendance Period Scheme เลือก Period Generation Pattern ได้สี่แบบ ได้แก่ เดือนปฏิทินตั้งแต่วันที่ 1 ถึงวันสุดท้ายของเดือน, แบ่งเดือนตามวันตัด เช่น 1–15 และ 16–วันสุดท้าย, รอบทุก N วันหรือสัปดาห์จากวันที่อ้างอิง และปฏิทินกำหนดเองที่สร้างช่วงล่วงหน้า ทุกแบบต้องสร้าง Period ต่อเนื่องโดยไม่ซ้อนและไม่มีช่องว่าง ชื่อกลุ่มพนักงาน เช่น รายวันหรือรายเดือน เป็นเพียงชื่อทางธุรกิจและไม่ถูก Hard-code เป็นกติกาวัน เหตุผลคือ Company อาจเรียกประเภทพนักงานเหมือนกันแต่ใช้วันตัดต่างกัน และบางแห่งมีรอบพิเศษที่สูตรมาตรฐานแทนไม่ได้
