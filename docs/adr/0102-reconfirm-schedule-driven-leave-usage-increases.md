# ให้พนักงานยืนยันใหม่เมื่อการเปลี่ยนตารางเพิ่มสิทธิ์ลา

เมื่อ Leave Schedule Change Review พบว่าตารางใหม่ทำให้ Leave Usage สูงกว่าค่าที่ Employee เคยยืนยัน ระบบห้ามเพิ่มยอดโดยอัตโนมัติและต้องนำ Leave Request เข้า Reconfirmation เพื่อแสดงผลต่างให้ Employee ยืนยันใหม่ หาก Leave Usage ลดลง ผู้มี Permission สามารถรับรองผลใหม่และแจ้ง Employee โดยไม่ต้องขอการยืนยันซ้ำ เหตุผลคือการใช้สิทธิ์เพิ่มเป็นภาระต่อยอดคงเหลือของ Employee จึงต้องได้รับความยินยอม ส่วนการลดการใช้สิทธิ์ไม่สร้างภาระเพิ่มแต่ยังต้องโปร่งใส
