# ใช้ Membership ตามช่วงวันที่ภายใน Period ร่วม

Employee ที่เริ่มงาน ลาออก หรือเปลี่ยน Employee Attendance Period Assignment กลาง Attendance Period ยังคงอยู่ใน Period ปกติของ Scheme โดยระบบสร้าง Attendance Period Membership เฉพาะ Work Date ที่สถานะการจ้างและ Assignment มีผล ไม่สร้าง Period ย่อยรายบุคคล วันที่ก่อนเริ่มงานหรือหลังสิ้นสุดงานไม่ถือเป็น Absence และรายงานต้องระบุว่า Employee เป็นสมาชิกเพียงบางช่วงของงวด เหตุผลคือขอบเขต Period เป็นรอบรับรองร่วมของ Company ส่วนช่วงที่แต่ละ Employee ต้องถูกคำนวณเป็นคุณสมบัติของ Membership ไม่ใช่งวดใหม่
