# แยกตารางไม่ครบออกจากการขาดงาน

LAOO_TIME ระบุ Work Date ของ Employee ที่ต้องลงเวลาแต่ไม่มีทั้งตารางงานและ Day Off เป็น Schedule Gap และไม่คำนวณ Absence จนกว่าจะจัดตารางครบ เหตุผลคือเมื่อไม่มี Net Scheduled Minutes ระบบไม่รู้ว่าพนักงานควรทำงานช่วงใด และการตีความข้อมูลตั้งค่าที่ขาดเป็นการขาดงานจะลงโทษพนักงานผิดคน
