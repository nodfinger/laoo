# นับ OT เฉพาะช่วงที่อนุมัติและทำงานจริง

LAOO_TIME นับ OT Worked Minutes เฉพาะส่วนที่ Attendance Event จริงซ้อนกับ Approved OT Assignment โดยไม่ถือว่าการอยู่เกินเวลาหรือการมีตาราง OT เพียงอย่างเดียวเป็น OT เหตุผลคือการนับจากเวลาออกงานอย่างเดียวทำให้การอยู่ต่อโดยไม่ได้รับมอบหมายกลายเป็น OT ขณะที่การนับจากรายการอนุมัติอย่างเดียวจะจ่ายผลให้เวลาที่ไม่ได้ทำจริง
