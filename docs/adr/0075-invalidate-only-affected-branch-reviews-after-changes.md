# ยกเลิกการรับรองเฉพาะสาขาที่ผลเปลี่ยน

เมื่อ Branch Period Review รับรองแล้ว แต่ Attendance Period ยังไม่ Finalize และมี Attendance Event, Leave หรือ Time Adjustment ใหม่ที่เปลี่ยน Attendance Result ระบบต้องยกเลิกสถานะรับรองเฉพาะ Home Branch ของ Work Date ที่ได้รับผลกระทบ พร้อมแสดงรายการและผลต่างให้ตรวจรับรองใหม่ Branch อื่นที่ผลไม่เปลี่ยนยังคงสถานะรับรองเดิม เหตุผลคือการคงคำรับรองไว้หลังข้อมูลเปลี่ยนทำให้คำรับรองไม่ตรงกับผลล่าสุด ขณะที่การยกเลิกทุก Branch เพิ่มงานซ้ำโดยไม่จำเป็น
