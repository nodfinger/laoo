# แก้หลายจุดเวลาของ Work Date เดียวในคำขอเดียว

Time Correction Request หนึ่งรายการมี Time Correction Request Detail หลายรายการสำหรับแก้ฝั่งเข้าและออกของ Attendance Session Rule หนึ่งหรือหลายรอบใน Work Date เดียวกันได้ ทุก Detail ใช้เหตุผลและหลักฐานของเหตุการณ์ร่วมกันและต้องอนุมัติหรือส่งกลับทั้งชุด ไม่อนุมัติบาง Detail แล้วสร้างผลเพียงบางส่วน เหตุผลคือกรณีลืมลงทั้งเข้าและออกเป็นเหตุการณ์เดียว การแยกคำขอหรืออนุมัติครึ่งชุดอาจทำให้ยังเกิด Incomplete Attendance และทำให้หลักฐานกระจัดกระจาย
