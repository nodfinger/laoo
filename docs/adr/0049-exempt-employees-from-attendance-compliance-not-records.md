# ยกเว้นการตรวจวินัยเวลาโดยไม่ยกเลิกข้อมูลเวลา

เมื่อ Attendance Requirement ระบุว่า Employee ไม่ต้องลงเวลา ระบบยังคงตาราง การลา และ Attendance Event ที่ได้รับไว้ แต่ไม่สร้างสถานะ Absence, Late Arrival, Early Departure หรือ Incomplete Attendance ในช่วงที่ได้รับยกเว้น เวลาทำงานจริงสามารถแสดงเป็นข้อมูลประกอบได้แต่ไม่ถือเป็นผลตรวจวินัยเวลา เหตุผลคือการยกเว้นมีความหมายว่าไม่บังคับพิสูจน์การมาตามตาราง ไม่ได้หมายความว่าพนักงานไม่มีตาราง ไม่มีการลา หรือห้ามเก็บหลักฐานเวลาที่เกิดขึ้นจริง
