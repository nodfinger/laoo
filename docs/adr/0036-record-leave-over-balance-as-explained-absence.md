# บันทึกการลาเกินสิทธิ์เป็นขาดงานที่มีเหตุผล

LAOO_TIME ไม่สร้างยอดลาติดลบ แต่ยังรับ Leave Request ที่เกิน Available Leave Balance โดยส่วนที่มีสิทธิ์สร้าง Leave Usage และส่วนเกินสร้าง Explained Absence ด้วยเหตุผล Leave Balance Exceeded ซึ่งยังรวมในสถิติขาดงาน เหตุผลคือองค์กรต้องเก็บเหตุผลที่พนักงานไม่มาทำงานแม้สิทธิ์ลาไม่พอ โดยไม่ทำให้ยอดสิทธิ์สูญเสียความหมายหรือซ่อนการขาดงานเป็นการลา
