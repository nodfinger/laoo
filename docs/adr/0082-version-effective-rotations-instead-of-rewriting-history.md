# แก้ Rotation ที่ใช้งานแล้วด้วย Version ใหม่

Rotation Pattern ที่เริ่มใช้แล้วห้ามแก้ผลย้อนหลังอัตโนมัติ การเปลี่ยนต้องสร้าง Version ใหม่พร้อมวันที่เริ่มใช้ โดยเริ่มจาก Work Date ในอนาคตหรือวันนี้เมื่อ Period ยังเปิดและผู้ใช้มี Permission หากต้องแก้ Work Date ย้อนหลังให้ใช้ Schedule Override หรือเปิด Attendance Period ที่เกี่ยวข้องพร้อมเหตุผล การเปลี่ยนผลในงวดเปิดต้องคำนวณใหม่และยกเลิก Branch Period Review ที่ได้รับผลกระทบ เหตุผลคือการเขียนทับ Pattern เดิมจะทำให้ตารางที่ Employee เคยปฏิบัติและ Attendance Result เดิมเปลี่ยนโดยไม่มีหลักฐาน
