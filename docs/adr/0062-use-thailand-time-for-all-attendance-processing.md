# ใช้เวลาประเทศไทยกับการประมวลผลเวลาทั้งหมด

สถานะ: แทนที่ ADR 0029 และปรับขอบเขตการตีความเวลาใน ADR 0060

LAOO_TIME ใช้ Thailand Business Time คือ `Asia/Bangkok` (`UTC+07:00`) กับทุก Company และ Branch สำหรับตีความ Source Event Time จากเครื่องทั่วไป ตารางงาน Attendance Classification Window และ Work Date โดยตัดการตั้งค่า Branch Time Zone ออก ระบบยังเก็บเวลาต้นฉบับจากเครื่อง เวลาไทยที่ใช้คำนวณ Event Time UTC ที่แปลงแล้ว และ Received Time UTC เพื่อการตรวจสอบ แต่ไม่มีการเลือกเขตเวลาตามสาขา เหตุผลคือขอบเขตธุรกิจของระบบยึดเวลาประเทศไทยและเครื่องลงเวลาทั่วไปให้เวลาท้องถิ่นของไทย การรองรับเขตเวลารายสาขาเพิ่มความซับซ้อนโดยไม่ตรงข้อกำหนดปัจจุบัน
