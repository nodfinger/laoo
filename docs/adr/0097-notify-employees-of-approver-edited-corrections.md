# แจ้งพนักงานเมื่อผู้อนุมัติแก้คำขอเวลา

เมื่อผู้อนุมัติเปลี่ยนค่าที่ Employee ระบุใน Time Correction Request ต้องบังคับระบุเหตุผลใน Approval Edit Log และแจ้ง Employee เมื่อคำขอได้รับอนุมัติ My Attendance History ต้องแสดงค่าที่ Employee ขอ ค่าที่อนุมัติจริง เหตุผล และผู้แก้ โดย Employee อ่านได้แต่แก้ Log ไม่ได้ เหตุผลคือผลที่อนุมัติอาจต่างจากคำขอต้นฉบับและมีผลต่อสถิติเวลา Employee จึงต้องเห็นความแตกต่างและที่มาอย่างโปร่งใส
