# กำหนดเกณฑ์เวลาแบบ Company Default และ Session Override

Company กำหนด Attendance Tolerance เริ่มต้นสำหรับ Late Arrival และ Early Departure และแต่ละ Attendance Session Rule สามารถกำหนดค่าทับได้ ค่าที่ใช้ต้องอยู่ใน Policy Version ที่มีวันที่เริ่มใช้ เหตุผลคือ Company ต้องมีค่ากลางเพื่อลดการตั้งค่าซ้ำ แต่รอบงานบางประเภทอาจต้องใช้ความเคร่งครัดต่างกัน การกำหนดทับระดับ Session Rule ทำให้รองรับความแตกต่างโดยไม่สร้างกะซ้ำทั้งชุด
