# กันสิทธิ์ลาระหว่างรออนุมัติ

LAOO_TIME ให้ Leave Request ที่รออนุมัติสร้าง Reserved Leave เพื่อลด Available Leave Balance โดยยังไม่เกิด Leave Usage และยังไม่เปลี่ยนผลการมาทำงานจนกว่าจะอนุมัติ เมื่อคำขอถูกปฏิเสธหรือยกเลิกให้คืนยอดที่กันไว้ เหตุผลคือการไม่กันยอดเปิดทางให้พนักงานยื่นคำขอซ้อนเกินสิทธิ์ ส่วนการตัดสิทธิ์ทันทีจะทำให้รายการที่ยังไม่อนุมัติมีผลเหมือนข้อเท็จจริงแล้ว
