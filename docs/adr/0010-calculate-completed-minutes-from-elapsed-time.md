# คำนวณนาทีจากระยะเวลาจริงและตัดเศษครั้งเดียว

LAOO_TIME เก็บ Attendance Event ละเอียดถึงวินาที แต่รายงานเวลาเป็น Completed Minute ที่ได้จากระยะเวลาจริงและตัดเศษวินาทีทิ้งครั้งเดียวเมื่อสรุปแต่ละช่วง เช่น 08:00–08:59 เท่ากับ 59 นาที และ 08:00:40–09:00:20 เท่ากับ 59 นาที เหตุผลคือการปัดเวลาเข้าและออกแยกกันอาจเพิ่มหรือลดเวลาเกินจริง และการนับรวมหัวท้ายไม่ตรงกับเวลาที่ผ่านไปจริง
