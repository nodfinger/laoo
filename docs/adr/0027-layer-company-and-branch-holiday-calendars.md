# ใช้ปฏิทินวันหยุดระดับ Company พร้อมข้อยกเว้นของ Branch

LAOO_TIME ใช้ Holiday Calendar ระดับ Company และให้ Branch เลือกปฏิทินเฉพาะหรือเพิ่มและยกเว้นบางวันได้ โดยวันหยุดมีลำดับเหนือ Group Shift Rotation แต่ Schedule Override มีลำดับสูงสุด เหตุผลคือสาขาต่างพื้นที่อาจมีวันหยุดไม่เหมือนกัน และการเปลี่ยนปฏิทินส่วนกลางไม่ควรบังคับทุกสาขา ขณะเดียวกันองค์กรยังต้องสามารถจัดพนักงานมาทำงานเฉพาะวันหยุดได้
