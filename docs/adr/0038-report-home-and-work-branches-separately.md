# แยกสาขาสังกัดออกจากสาขาที่ปฏิบัติงาน

LAOO_TIME เก็บ Home Branch จาก Employee Organization Assignment และ Work Branch จากตารางหรือ Schedule Override ของ Work Date เป็นคนละมิติ รายงานสามารถสรุปตามสาขาสังกัดหรือตามสถานที่ปฏิบัติงานจริง และ Attendance Event ไม่เปลี่ยนสังกัดพนักงานเอง เหตุผลคือพนักงานอาจไปช่วยงานต่างสาขาชั่วคราว การใช้ Branch ค่าเดียวจะทำให้ทั้งรายงานกำลังคนและรายงานภาระงานคลาดเคลื่อนอย่างใดอย่างหนึ่ง
