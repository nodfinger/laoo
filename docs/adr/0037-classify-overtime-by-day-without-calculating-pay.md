# แยกประเภท OT ตามชนิดวันโดยไม่คำนวณค่าจ้าง

LAOO_TIME นับงานที่มี Approved OT Assignment และ Attendance Event จริงใน Day Off หรือ Holiday เป็น OT Worked Minutes และแยก OT Day Category จาก OT ในวันทำงานปกติ ระบบบันทึกนาทีและประเภทวันเท่านั้นโดยไม่คำนวณอัตราหรือเงินค่าจ้าง เหตุผลคือข้อมูลเวลาเป็นข้อเท็จจริงต้นทางของ Payroll แต่กฎตัวคูณและค่าจ้างเป็นอีกขอบเขตหนึ่งที่อาจต่างกันตามสัญญาและกฎหมาย
