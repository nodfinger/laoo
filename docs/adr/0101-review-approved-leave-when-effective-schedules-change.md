# ตรวจคำขอลาที่อนุมัติเมื่อมีการเปลี่ยนตาราง

เมื่อ Schedule Override, Work Schedule Group Assignment หรือ Rotation Version เปลี่ยนตารางของ Work Date ที่มี Leave Request อนุมัติ ระบบคงคำขอและสถานะอนุมัติเดิม แต่คำนวณ Leave-covered Minutes กับตารางใหม่ หาก Leave Usage หรือช่วงที่ได้รับความคุ้มครองเปลี่ยนต้องสร้าง Leave Schedule Change Review และยกเลิก Branch Period Review ที่ได้รับผลกระทบ หาก Attendance Period Finalized ต้องเปิดงวดก่อน เหตุผลคือเจตนาการลาที่อนุมัติไม่ควรหายเพราะตารางเปลี่ยน แต่ผลสิทธิ์ต้องอ้างตารางที่มีผลและห้ามเปลี่ยนเงียบ ๆ
