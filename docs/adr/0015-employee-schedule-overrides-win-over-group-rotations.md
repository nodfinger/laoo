# ให้ข้อยกเว้นรายบุคคลอยู่เหนือตารางกลุ่ม

LAOO_TIME ใช้ Schedule Override ที่ระบุ Employee และ Work Date สำหรับการเปลี่ยนกะเฉพาะราย โดย Override มีลำดับเหนือกว่า Group Shift Rotation และต้องเก็บเหตุผลกับผู้ดำเนินการ เหตุผลคือการแก้ Rotation Pattern เพื่อเปลี่ยนกะของคนเดียวจะกระทบสมาชิกทั้งกลุ่มและทำลายตารางต้นฉบับ ขณะที่ข้อยกเว้นแยกช่วยรักษาประวัติและขอบเขตผลกระทบ
