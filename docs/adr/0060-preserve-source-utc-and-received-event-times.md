# เก็บเวลาต้นฉบับ เวลา UTC และเวลารับข้อมูลแยกกัน

Attendance Event ต้องเก็บ Source Event Time ต้นฉบับพร้อมเขตเวลาหรือ Offset, Event Time UTC ที่แปลงแล้ว และ Received Time UTC แยกกันโดยห้ามเขียนทับข้อมูลต้นฉบับ หากนาฬิกาแหล่งข้อมูลผิดให้ติดธงตรวจสอบและแก้ผลผ่าน Time Adjustment เหตุผลคือข้อมูลอาจถูกส่งล่าช้าหรือนำเข้าย้อนหลัง เวลาเกิดเหตุการณ์กับเวลาที่ระบบรับจึงเป็นคนละข้อเท็จจริง และต้องรักษาทั้งคู่เพื่อพิสูจน์การแปลงเวลาและวิเคราะห์ปัญหาอุปกรณ์
