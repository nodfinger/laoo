# ข้ามเหตุการณ์เวลาที่นำเข้าซ้ำกันทั้งหมด

LAOO_TIME ไม่สร้าง Attendance Event ใหม่เมื่อข้อมูลที่นำเข้ามี Company, Employee, เวลา UTC, แหล่งหรืออุปกรณ์ และประเภท Event ตรงกับรายการเดิมทั้งหมด โดยจัดเป็น Replay Duplicate และข้ามข้อมูล เหตุผลคือระบบต้นทางอาจส่งไฟล์หรือโอนช่วงเวลาเดิมหลายรอบ การเก็บซ้ำจะทำให้เกิดข้อมูลเทียม ขณะที่การแตะจริงหลายครั้งซึ่งมีรหัสหรือเวลาแตกต่างกันยังต้องเก็บครบและใช้กติกา Primary กับ Duplicate Attendance Event ตามปกติ
