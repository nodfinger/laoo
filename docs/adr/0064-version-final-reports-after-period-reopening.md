# เก็บรายงานทางการทุก Version หลังเปิดงวดแก้

เมื่อ Attendance Period ที่ Finalized ถูกเปิดแก้และปิดใหม่ ระบบสร้าง Final Attendance Report Version ใหม่โดยไม่แก้ไขหรือลบฉบับเดิม ฉบับใหม่ต้องอ้างอิงฉบับที่แทนที่ พร้อมเหตุผล ผู้เปิดงวด และเวลาสร้าง การส่งออกครั้งใหม่ใช้ Version ล่าสุด แต่ผู้มี Permission ตรวจย้อนหลังทุก Version ได้ เหตุผลคือรายงานเดิมอาจถูกส่งต่อหรือใช้ตัดสินใจแล้ว การเขียนทับจะทำให้ไม่สามารถตรวจความแตกต่างและที่มาของการแก้ไขได้
