# เก็บ Snapshot สมาชิกเมื่ออนุมัติ OT แบบกลุ่ม

เมื่ออนุมัติ OT ให้ Work Schedule Group หรือ Employee หลายคน ระบบสร้าง OT Approval Batch ที่เก็บ Snapshot สมาชิก ณ เวลาอนุมัติและสร้าง Approved OT Assignment ราย Employee การเข้าออกกลุ่มภายหลังไม่เปลี่ยน Assignment ที่อนุมัติแล้ว หากต้องเพิ่มหรือลด Employee ต้องทำรายการแก้พร้อมประวัติ เหตุผลคือ Work Schedule Group ใช้จัดตารางและสมาชิกเปลี่ยนตามช่วงเวลา แต่การอนุมัติ OT เป็นข้อเท็จจริงเฉพาะครั้งที่ต้องรักษารายชื่อผู้ได้รับอนุมัติเดิม
