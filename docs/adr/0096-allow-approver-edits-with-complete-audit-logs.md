# อนุญาตให้ผู้อนุมัติแก้คำขอพร้อมเก็บ Log ครบถ้วน

ผู้อนุมัติที่มี Permission สามารถแก้เวลาหรือรายละเอียดใน Time Correction Request ก่อนอนุมัติได้ โดยระบบต้องรักษาค่าที่ Employee ส่งมาและสร้าง Approval Edit Log ทุกครั้ง ซึ่งเก็บค่าก่อนแก้ ค่าหลังแก้ ผู้ดำเนินการ วันเวลา และลำดับการแก้ ห้ามเขียนทับจนไม่เห็นต้นฉบับ Time Adjustment ที่สร้างต้องอ้างทั้งคำขอต้นฉบับและค่าฉบับที่อนุมัติ เหตุผลคือผู้อนุมัติอาจมีหลักฐานที่ถูกต้องกว่าและควรแก้ให้จบใน Workflow ได้ แต่การแก้ดังกล่าวต้องตรวจสอบย้อนหลังได้เสมอ
