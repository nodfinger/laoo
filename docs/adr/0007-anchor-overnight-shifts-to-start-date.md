# ยึดวันเริ่มกะเป็น Work Date ของกะข้ามวัน

LAOO_TIME ให้เวลาทั้งกะรวมถึงช่วงหลังเที่ยงคืนอยู่ภายใต้ Work Date ตามวันที่เริ่มกะ ขณะที่ Attendance Event ยังคงวันเวลาจริง เหตุผลคือการแบ่งกะข้ามวันตามวันปฏิทินจะทำให้การจับคู่ตารางงาน การลา การขาดงาน และ OT แตกเป็นสองวันและตีความยาก แลกกับการที่รายงานตามวันปฏิทินต้องแยกจากรายงานตาม Work Date อย่างชัดเจน
