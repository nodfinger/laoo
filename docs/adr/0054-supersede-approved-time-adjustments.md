# แทนที่รายการปรับเวลาที่อนุมัติแล้วด้วยรายการใหม่

Time Adjustment ที่อนุมัติแล้วห้ามแก้ไขหรือลบ หากพบว่าผิดต้องสร้าง Superseding Time Adjustment ที่อ้างอิงและยกเลิกผลของรายการเดิม พร้อมเหตุผล ผู้ดำเนินการ และเวลา แล้วคำนวณ Attendance Result ใหม่โดยเก็บทั้งสองรายการไว้ เหตุผลคือผลเวลาอาจผ่านการตรวจสอบหรือถูกใช้ในรายงานแล้ว การเขียนทับทำให้ไม่สามารถพิสูจน์ได้ว่าใครเปลี่ยนข้อเท็จจริงใดและเมื่อใด
