# ใช้คู่เวลาเป็น Session แล้วตัดกับช่วงงานและ OT

LAOO_TIME สร้าง Attendance Session จากคู่ Primary Attendance Event ฝั่งเข้าและออก แล้วนำช่วง Session ไปตัดกับ Shift Segment, BREAK และ Approved OT Assignment เพื่อคำนวณผล Session เดียวจึงครอบคลุมงานปกติต่อเนื่องถึง OT ได้โดยไม่บังคับออกและเข้าใหม่ เหตุผลคือ Event แสดงช่วงที่พนักงานอยู่จริง ส่วนตารางและการอนุมัติเป็นผู้กำหนดความหมายของแต่ละนาที การจับคู่ใหม่ทุก Segment จะเพิ่ม Incomplete Attendance โดยไม่จำเป็น
