# กำหนดการยกยอดลาต่อ Company และเก็บประวัติการหมดอายุ

LAOO_TIME ให้แต่ละ Company กำหนด Leave Carryover Rule แยกตาม Leave Type ว่าไม่ยกยอด ยกทั้งหมด หรือยกได้สูงสุดเท่าใด รวมถึงวันหมดอายุของยอดที่ยก ระบบใช้ยอดที่หมดอายุก่อนและบันทึก Leave Expiration เป็นประวัติแทนการแก้ยอดทิ้ง เหตุผลคือนโยบายแต่ละองค์กรต่างกันและยอดคงเหลือต้องอธิบายย้อนหลังได้จากสิทธิ์ การใช้ การปรับ และการหมดอายุ
