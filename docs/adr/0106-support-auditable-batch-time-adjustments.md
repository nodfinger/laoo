# รองรับการปรับเวลาแบบกลุ่มที่ตรวจสอบย้อนหลังได้

กรณีเหตุการณ์ร่วม เช่น เครื่องลงเวลาเสียทั้ง Branch ระบบรองรับ Time Adjustment Batch ที่ระบุ Time Adjustment Reason และหลักฐานร่วมกัน พร้อมรายละเอียดเวลาแยกราย Employee ระบบต้องตรวจทุก Detail ก่อนส่ง Time Adjustment Approval Workflow และเมื่ออนุมัติสร้าง Time Adjustment รายบุคคลที่อ้างกลับไปยัง Batch เหตุผลคือการคีย์ทีละคนทำงานช้าและสร้างข้อมูลเหตุผลซ้ำ แต่การเก็บผลเป็นรายการรวมเดียวจะตรวจและแก้ผลราย Employee ไม่ได้
