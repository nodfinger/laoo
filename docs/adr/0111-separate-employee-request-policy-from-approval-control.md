# แยก Employee Request Policy จาก Approval Control Profile

Company กำหนด Employee Request Policy เป็น SELF_SERVICE_AND_PROXY, PROXY_ONLY หรือ SELF_SERVICE_ONLY แยกต่อ Leave Request, Leave Cancellation, Time Correction และ Reconfirmation โดยไม่ผูกกับรูปแบบอนุมัติ Employee ทำเองได้เมื่อ Policy อนุญาต มีสถานะการจ้างที่มีผลและ Active Login ที่ผูก Employee พร้อม Employee Self-Service Role แบบ Own Scope โดย PROXY_ONLY ต้องปฏิเสธรายการที่ Employee เริ่มเอง การเปิด SELF_SERVICE_ONLY ต้องถูกบล็อกและแสดง Employee ใน Scope ที่ Login ไม่พร้อม และหากเกิดภายหลังให้สร้าง Employee Request Access Gap ซึ่งแก้กรณีเร่งด่วนผ่าน Administrative Override ได้ ส่วน Proxy Submission ต้องใช้ ACT_ON_BEHALF และ On-Behalf Reason พร้อมบันทึกการแจ้ง Employee กับ Delivery Status โดย Notification Failure ไม่ Rollback ธุรกรรม; OT, Time Adjustment, Entitlement และ Period เป็น Administrative Action ไม่ใช่ Proxy Submission เพราะผู้เริ่มคำขอกับผู้ตัดสินเป็นคนละมิติของการควบคุม
