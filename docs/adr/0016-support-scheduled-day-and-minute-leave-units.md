# รองรับสิทธิ์ลาแบบวันตามตารางและแบบนาที

LAOO_TIME ให้ Leave Type เลือกหน่วยสิทธิ์เป็น Leave Day หรือ Minute-based Leave โดยลาครบ Net Scheduled Minutes ของ Work Date เท่ากับหนึ่ง Leave Day ไม่ว่ากะยาวกี่ชั่วโมง และลาบางช่วงใช้สิทธิ์ตามสัดส่วนของนาทีงานปกติสุทธิ เหตุผลคือสิทธิ์ที่สื่อสารเป็นวันต้องยุติธรรมกับพนักงานต่างรูปแบบกะ ขณะที่การบังคับทุกประเภทลาให้เป็นวันจะไม่รองรับการลาระยะสั้นที่ต้องคิดเป็นนาที
