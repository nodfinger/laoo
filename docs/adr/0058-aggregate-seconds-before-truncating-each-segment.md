# รวมวินาทีก่อนตัดเศษราย Segment

เมื่อ Shift Segment เดียวมี Attendance Session หลายรายการ ระบบรวมระยะเวลาจริงเป็นวินาทีของทุกส่วนที่ซ้อนกับ Segment ก่อน แล้วแปลงเป็น Completed Minute โดยตัดเศษเพียงครั้งเดียวตอนสรุป Segment เช่น 30 นาที 40 วินาทีสองช่วงเท่ากับ 61 Completed Minutes เหตุผลคือการตัดเศษแยกแต่ละ Session ทำให้พนักงานสูญเสียนาทีมากขึ้นตามจำนวนรอบลงเวลา ทั้งที่เวลาทำงานรวมเท่ากัน
