# จัดประเภทและเลือกเหตุการณ์เวลาด้วยช่วงที่กำหนดในตาราง

LAOO_TIME ใช้ Attendance Classification Window จัดประเภท Event ที่แหล่งบันทึกไม่ได้ระบุว่าเข้าออก โดยช่วงเข้างานเลือก Event แรกสุดเป็น Primary Attendance Event และช่วงออกงานเลือก Event สุดท้ายภายในช่วง ส่วน Event อื่นเก็บเป็น Duplicate Attendance Event เหตุผลคือข้อมูลต้นฉบับต้องคงครบ แต่การคำนวณต้องให้ผลแน่นอนเมื่อพนักงานบันทึกซ้ำ และช่วงออกงานต้องสะท้อนเวลาสุดท้ายที่ยังอยู่ในกรอบของกะ
