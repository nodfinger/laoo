# ใช้ช่วงพักตามตารางเป็นหลักในขอบเขตเริ่มต้น

LAOO_TIME ใช้ Shift Segment ประเภท BREAK เป็นหลักในการคำนวณ Break Deduction โดยหักเฉพาะส่วนที่ซ้อนกับ Attendance Session การแตะเครื่องระหว่างช่วงพักไม่ใช้เริ่มหรือสิ้นสุดเวลาพักและไม่เปลี่ยนนาทีพัก รายการดังกล่าวยังเก็บเป็น Unclassified Attendance Event เพื่อเป็นหลักฐาน เหตุผลคือขอบเขตเริ่มต้นกำหนดช่วงพักจากตารางอยู่แล้ว การตีความ Event ช่วงพักโดยไม่มีนโยบายเฉพาะจะทำให้ผลคำนวณไม่แน่นอนและขัดกับหลัก Classification Window ของระบบ หากอนาคต Company ต้องการใช้เวลาพักจริง ต้องเปิดเป็นนโยบายแยกอย่างชัดเจน
