# ให้ Core เป็นเจ้าของประวัติสังกัดพนักงานตามช่วงวันที่

LAOO ให้ Core เป็นเจ้าของ Employee Organization Assignment ที่เก็บ Branch ฝ่าย และแผนกแบบมีช่วงวันที่ และให้ LAOO_TIME เลือกสังกัดตาม Work Date ในรายงาน เหตุผลคือการใช้สังกัดปัจจุบันบน Employee จะย้ายประวัติเดือนเก่าไปอยู่หน่วยงานใหม่เมื่อพนักงานโยกย้าย และประวัติองค์กรเป็นข้อมูลร่วมที่ Business Project อื่นต้องอ้างได้ ไม่ควรเป็นข้อมูลเฉพาะของระบบเวลา
