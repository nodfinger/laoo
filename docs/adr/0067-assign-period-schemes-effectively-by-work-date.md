# ผูก Period Scheme ตาม Work Date ที่มีผล

Employee Attendance Period Assignment มีช่วงวันที่แบบไม่ซ้อนกันและ Employee มี Scheme ที่มีผลได้หนึ่งรายการต่อ Work Date เมื่อพนักงานเปลี่ยน Scheme กลางงวด Work Date ก่อนวันที่มีผลยังอยู่ Scheme เดิม และตั้งแต่วันที่มีผลอยู่ Scheme ใหม่ หากการเปลี่ยนย้อนหลังแตะ Attendance Period ที่ Finalized ต้องเปิดทุก Period ที่ได้รับผลกระทบพร้อมเหตุผลก่อน เหตุผลคือการเปลี่ยนประเภทการจ้างอาจเกิดกลางรอบจริง แต่ต้องไม่ย้าย Attendance Result ออกจากรายงานทางการเดิมอย่างเงียบ ๆ
