# ใช้งวดเปลี่ยนผ่านเชื่อม Scheme Version

เมื่อ Attendance Period Scheme Version ใหม่ต่อกับ Version เดิมแล้วเกิดช่องว่างหรือช่วงซ้อน ระบบต้องเสนอ Transition Attendance Period หนึ่งงวดเพื่อเชื่อมขอบเขต โดยแสดงรายการวันที่ล่วงหน้าและตรวจว่า Work Date ต่อเนื่องแบบไม่หายและไม่ซ้อนก่อนให้ผู้มี Permission ยืนยัน หลังงวดเปลี่ยนผ่านจึงสร้าง Period ตาม Pattern ใหม่ตามปกติ เหตุผลคือการบิดสูตรงวดเดิมหรือสูตรใหม่เพื่อแก้ช่วงรอยต่อจะทำให้กติกาปกติไม่ตรงความหมายและตรวจสอบย้อนหลังยาก
