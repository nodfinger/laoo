# ให้ Home Branch ตาม Work Date เป็นเจ้าของการรับรองงวด

Branch Period Review ใช้ Home Branch จาก Employee Organization Assignment ที่มีผลในแต่ละ Work Date เป็นเจ้าของการรับรอง ส่วน Work Branch สามารถตรวจและยืนยันหลักฐานการทำงานที่เกิดในพื้นที่ตนตาม Permission แต่ไม่เป็นผู้ปิดผลหลัก หาก Employee ย้ายสังกัดกลาง Attendance Period แต่ละ Home Branch รับรองเฉพาะ Work Date ที่ตนรับผิดชอบ เหตุผลคือ Home Branch เป็นเจ้าของข้อมูลบุคลากรและผลเวลา ขณะที่ Work Branch เป็นแหล่งยืนยันการปฏิบัติงานชั่วคราว การใช้ Work Branch เป็นเจ้าของจะทำให้พนักงานหนึ่งคนถูกกระจายความรับผิดชอบตามสถานที่ทำงานรายวัน
