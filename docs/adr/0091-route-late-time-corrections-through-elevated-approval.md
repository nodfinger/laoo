# ส่งคำขอแก้เวลาย้อนหลังผ่านการอนุมัติระดับสูง

Company กำหนด Time Correction Submission Window เป็นจำนวนวันย้อนหลังสำหรับกระบวนการปกติ Employee ยังส่งคำขอที่เกินช่วงหรือกระทบ Attendance Period ที่ Finalized ได้ แต่ต้องระบุเหตุผลและหลักฐานเพิ่มเติมและผ่าน Approval Workflow ระดับสูง เมื่ออนุมัติแล้วผู้มี Permission จึงเปิด Period และสร้าง Attendance Result Version ใหม่ Employee ไม่มีสิทธิ์เปิดงวดเอง เหตุผลคือความผิดพลาดจริงอาจพบหลังปิดงวดจึงไม่ควรห้ามแก้ทั้งหมด แต่การเปลี่ยนผลทางการต้องควบคุมเข้มกว่าคำขอในงวดเปิด
