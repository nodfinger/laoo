# Use one item master with usages and warehouse-level inventory

LAOO ใช้ Item master เดียวต่อ Company และให้ Item หนึ่งรายการมีหลาย Usage แทนการสร้างทะเบียนสินค้า วัสดุ อุปกรณ์ อะไหล่ และบริการซ้ำกัน สต็อกเป็นยอดระดับ Warehouse และ Item แบบ Serial แยกเป็น Item Instance เพื่อรักษาประวัติชิ้นงานจริง การออกเอกสารขายใช้ Inventory Fulfillment ระบุผู้ตัดสต็อกรายการแรก ทำให้ใบส่งของและใบกำกับภาษีที่อ้างรายการเดียวกันไม่ตัดซ้ำ แลกกับการต้องย้ายยอดเดิมและบังคับกำหนดคลังหลักก่อนเปิดใช้ระบบใหม่
