# ผูกช่วงจัดประเภทเวลากับ Work Date และจำนวนวันเลื่อน

LAOO_TIME กำหนด Attendance Classification Window ด้วยเวลาและ Work Date Offset เพื่อแยกช่วงของวันเริ่มกะกับวันถัดไป เช่น ช่วงออกของกะข้ามคืนเป็น 04:00–09:00 ที่ Day 1 เหตุผลคือการเก็บเฉพาะเวลาในนาฬิกาไม่สามารถบอกได้ว่า Event หลังเที่ยงคืนเป็นของกะก่อนหรือกะใหม่ และจะจับคู่ผิดเมื่อมีหลายกะอยู่ใกล้กัน
