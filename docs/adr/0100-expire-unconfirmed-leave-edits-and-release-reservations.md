# หมดอายุคำขอลาฉบับแก้ที่ไม่ยืนยัน

Company กำหนดจำนวนวันที่ Employee ต้องยืนยัน Leave Request หลังผู้อนุมัติแก้ไข หากไม่ยืนยันภายในกำหนด ระบบเปลี่ยนสถานะเป็น Reconfirmation Expired และคืน Reserved Leave อัตโนมัติ โดยคง Leave Request และ Approval Edit Log ไว้ตรวจสอบ หาก Employee ยังต้องการลาต้องส่งคำขอใหม่ เหตุผลคือการกันสิทธิ์โดยไม่มีกำหนดทำให้คำขออื่นใช้สิทธิ์ไม่ได้ ทั้งที่ Employee ยังไม่ยอมรับรายละเอียดฉบับแก้
