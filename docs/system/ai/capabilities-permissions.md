# ทะเบียนความสามารถ AI

เมนู 10008 อยู่ในตั้งค่าระบบของ Company เมื่อ Company เปิด AI Chat และผู้ใช้มีสิทธิ์เมนูเท่านั้น การปิด AI Chat ไม่ลบการตั้งค่าความสามารถ หลังเปิดอีกครั้งระบบนำค่าเดิมมาใช้

รายการที่รันได้กำหนดใน `AssistantCapabilities` ของ Backend เท่านั้น ตารางทะเบียนใช้เก็บชื่อและการตั้งค่ารายบริษัท ไม่สามารถใช้เพิ่ม SQL, URL หรือโค้ดที่รันได้ การเรียกทุกครั้งต้องตรวจ Company จาก session, AI Chat, การเปิดความสามารถ, แพ็กเกจ, เมนู, ScreenType, Action และขอบเขตข้อมูล

เริ่มด้วย `repair.track_own` (งานที่ผู้ใช้สร้าง), `repair.parts_cost` (ยอดต้นทุนอะไหล่ของงานที่เสร็จ ไม่รวมค่าแรง), และ `repair.create_own` (ต้องยืนยันและใช้รหัสป้องกันสร้างซ้ำ) หากบริษัทบังคับแนบรูป ให้ใช้หน้าแจ้งซ่อมปกติ การส่งอีเมลต้องระบุผู้รับและยืนยันทุกครั้ง เซิร์ฟเวอร์คำนวณยอดและตรวจสิทธิ์ซ้ำก่อนส่งผ่าน SMTP ของบริษัท

เพิ่ม `travel.claim_summary` สำหรับสรุปยอดใบเบิกเดินทางตามช่วงเวลา ประเภทค่าใช้จ่าย และขอบเขตที่ผู้ใช้ดูได้ในเมนู 66001 ตัวอย่างคำถามเก็บถาวรใน `TDADAiCapabilityCompany.ExamplesJson` และแก้/เปิดใช้ผ่านเมนู 10008 ได้ ความสามารถนี้อ่านอย่างเดียว ไม่คืนรายชื่อบุคคล และ migration ลงทะเบียนแบบปิดไว้ก่อนในแต่ละบริษัท

ทั้งสามความสามารถสามารถกำหนดให้ส่งออก PDF, PNG, HTML และส่งอีเมลแยกรายบริษัทได้ โดยระบบตรวจสถานะ AI Chat ความสามารถ แพ็กเกจ และสิทธิ์ผู้ใช้ซ้ำก่อนสร้างรายงานหรือส่งอีเมล สำหรับใบแจ้งซ่อมที่สร้างผ่าน AI การส่งออกหรือส่งเมลจำกัดเฉพาะใบที่ผู้ใช้คนปัจจุบันสร้างภายในบริษัทของตน

เมื่อพัฒนา Project เพิ่ม ให้สร้างตัวทำงาน Backend ที่กำหนดรหัสความสามารถ, Project, MenuCode, ScreenType และ Action แน่นอน เพิ่มใน allowlist แล้วเพิ่ม migration ของ Project เพื่อลงทะเบียน metadata แบบ insert-if-missing โดยค่าเริ่มต้นรายบริษัทต้องปิด และห้ามเขียนทับค่าที่ผู้ดูแลตั้งไว้ สร้างการทดสอบสิทธิ์ต่างบริษัท แพ็กเกจที่ปิด การปฏิเสธเมนูและ Action และข้อมูลที่ได้รับอนุญาต ก่อนติดตั้งด้วย migration runner ของโครงการ ห้ามให้โมเดลสร้าง SQL หรือเลือก CompanyID เอง

ตรวจพื้นฐานด้วย `dotnet run --project tools/assistant-safety-tests -- --database` (อ่านฐานข้อมูลเท่านั้น) และ `flutter test test/assistant/assistant_report_test.dart test/assistant/assistant_greeting_test.dart` การส่งอีเมลจริงต้องมี SMTP ของบริษัทและผู้ใช้ยืนยันผู้รับ
