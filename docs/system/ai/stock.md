# AI สต๊อก

## ข้อกำหนดและพฤติกรรมที่พบในโค้ด

Agent `stock` ลงทะเบียน `stock.serial_lookup` ผูก `LAOO_STOCK`, เมนู `08006`, Action `VIEW` และ API `GET /api/assistant/stock/serial` ตรวจ capability ก่อนค้น ตัวอย่าง: “ค้นหา Serial” ดู [ทะเบียน](README.md)

## แบบร่าง / ยังไม่ยืนยัน

เอกสาร Agent เก่าเคยระบุว่ายังไม่มีความสามารถสต๊อก แต่โค้ดปัจจุบันประกาศค้น Serial แล้ว ต้องตรวจการเปิดใช้จริงรายบริษัทและสิทธิ์ก่อนสรุปว่าใช้งานได้
