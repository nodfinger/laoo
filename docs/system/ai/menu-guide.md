# AI ช่วยค้นหาเมนู

## ข้อกำหนดและพฤติกรรมที่พบในโค้ด

`core.menu_guide` เป็นความสามารถส่วนกลาง ผูก `LAOO_AI`, เมนู `10008`, Action `VIEW` โดย `AssistantIntentClassifier`, `MenuGuideSearch` และ `AssistantMenuGuideController` ช่วยรับคำขอและค้นตามสิทธิ์ API อยู่ใต้ `/api/assistant/menu-guide` ตัวอย่าง: “เริ่มใช้งาน”, “จำไม่ได้”, “ช่วยหน่อย”

## แบบร่าง / ยังไม่ยืนยัน

คำค้นที่เปิดใช้งานจริงขึ้นกับตัวอย่างที่ตั้งไว้ในแต่ละบริษัทและสิทธิ์ผู้ใช้; ไม่อนุมานว่าทุกคำตรงกับความสามารถในทุกบริษัท
