# Agent ห้องประชุม: การสำรวจ API และแผนความสามารถ

Agent `meeting` อยู่ในทะเบียน Backend ถาวร สิทธิ์ไม่ได้เกิดจากชื่อ Agent แต่ตรวจ AI Chat, การเปิดความสามารถรายบริษัท, แพ็กเกจ LAOO_MEETING และสิทธิ์เมนู/การกระทำทุกครั้งก่อนเรียกงาน

| ความสามารถ | API ต้นทาง | เมนู / สิทธิ์ | สถานะ |
|---|---|---|---|
| ค้นหาห้องประชุมว่าง | POST meeting-room-bookings/availability (อ่านอย่างเดียว) | 21001 / VIEW | พัฒนาแล้ว ต้องทดสอบสิทธิ์และเปิดใช้รายบริษัท |
| การจองห้องประชุมของฉัน | GET meeting-room-bookings?mine=true | 21001 / VIEW | พัฒนาแล้ว ต้องทดสอบสิทธิ์และเปิดใช้รายบริษัท |
| คำเชิญประชุมของฉัน | GET my-meeting-invitations | 21003 / VIEW | พัฒนาแล้ว ต้องทดสอบสิทธิ์และเปิดใช้รายบริษัท |
| ปฏิทินการจอง | GET meeting-room-bookings/calendar | 21002 / VIEW | รอพัฒนา |
| จอง แก้ไข ยกเลิกห้องประชุม | POST, PUT, DELETE meeting-room-bookings | 21001 / CREATE, EDIT, DELETE | รอพัฒนา ต้องยืนยันและตรวจเจ้าของรายการ |
| ตรวจรายการรออนุมัติและตัดสินใจ | GET approval-requests; POST approval-requests/{id}/decision | 21004 / VIEW, EDIT | รอพัฒนา ต้องตรวจผู้อนุมัติ |
| ตอบรับคำเชิญและจัดการผู้เข้าร่วม | meeting-participant-responses; meeting-room-bookings/{id}/participants | 21003 / VIEW, EDIT และสิทธิ์เจ้าของ | รอพัฒนา |
| ตรวจและบันทึกการเข้าใช้ห้อง | meeting-room-usage; meeting-attendance | ตรวจเมนูและสิทธิ์ต้นทาง | รอพัฒนา |
| กำหนดอาหาร สรุปอาหาร และแจกอาหาร | meeting-food-plans, meeting-food-order-summaries, meeting-food-distribution | 21005, 21006, 21007 / ตาม Action | รอพัฒนา |
| ขออุปกรณ์และติดตามงานจัดเตรียม | meeting-equipment-requests | 22005 / ตาม Action | รอพัฒนา |
| แจ้งปัญหาห้องประชุม | meeting-room-issues | 22003 / ตาม Action | รอพัฒนา |
| จัดการห้อง กฎห้อง อาคาร และอาหาร | meeting-rooms, meeting-rooms/{id}/rules, meeting-structure, meeting-foods | 23002, 23001, 23004 / ตาม Action | รอพัฒนา |
| รายงานการใช้ห้องและผู้ไม่มา | meeting-attendance/utilization-report, meeting-attendance/no-show-report | ตรวจเมนูและสิทธิ์รายงานก่อนพัฒนา | รอพัฒนา |

ตัวอย่างสำหรับความสามารถที่ยังไม่พร้อม เช่น “จองห้องพรุ่งนี้เก้าโมง”, “ยกเลิกห้องที่จองไว้”, “มีคำขอรออนุมัติไหม”, “สรุปจำนวนอาหารประชุม” และ “ห้องนี้ใช้งานบ่อยแค่ไหน” เป็นแนวทางสำหรับการพัฒนา ไม่สามารถใช้สั่งงานผ่าน Chat ได้ในรอบนี้

การค้นหาห้องว่างต้องระบุวันและเวลาในวันเดียวกัน การจองและคำเชิญแสดงรายการที่จะมาถึงสูงสุด 20 รายการ การติดตั้งตัวอย่างเริ่มต้นต้องไม่ทับการตั้งค่าเดิม และให้ความสามารถใหม่ปิดเป็นค่าเริ่มต้น
