# Laoo Solutions Documentation

Version: 1.0  
Baseline date: 2026-08-09  
Status: Approved baseline

เอกสารชุดนี้เป็นแหล่งข้อกำหนดหลักของ Laoo Solutions และ Laoo Plaza ใช้ได้กับสมาชิกทีมและเครื่องมือ AI ทุกชนิด

## เริ่มต้นใช้งาน

1. อ่าน `DOCUMENTATION_GUIDE.md` เพื่อหาเอกสารที่สัมพันธ์กับงาน
2. อ่าน `PROJECT_CONTEXT.md` และเอกสารบังคับของหัวข้อนั้น
3. ตรวจ `DECISIONS.md` เมื่อมีข้อสงสัยเกี่ยวกับมติล่าสุด
4. ห้ามอ้างอิงเอกสารที่อยู่ใน `DOCUMENT_CLEANUP_REPORT.md` ว่าเป็นไฟล์ยกเลิก

## ลำดับความสำคัญเมื่อเอกสารขัดกัน

1. `DECISIONS.md` รายการล่าสุดที่มีสถานะ Approved
2. เอกสาร Architecture หรือ Standard เฉพาะเรื่องใน Baseline นี้
3. API Contract ที่ระบุสถานะ Current
4. Meeting Summary และ History ใช้เพื่ออธิบายที่มาเท่านั้น

หากยังตัดสินไม่ได้ ให้หยุดและถาม Product Owner ห้ามเดาข้อกำหนดเอง
