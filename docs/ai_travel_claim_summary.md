# สรุปค่าเบิกเดินทางด้วย AI ส่วนกลาง

ความสามารถ `travel.claim_summary` อยู่ในทะเบียน AI ส่วนกลางและใช้ตัวอย่างคำถามที่จัดเก็บใน `TDADAiCapabilityCompany.ExamplesJson` เพื่อจับคู่คำถาม โดยผู้ดูแลแก้ไขตัวอย่างและเปิดใช้งานได้จากเมนูจัดการความสามารถ AI (10008) ตัวอย่างที่เพิ่มจะคงอยู่ในฐานข้อมูล ไม่ได้ฝึกหรือส่งข้อความไปฝึกโมเดลภายนอก

## คำถามที่รองรับ

- ยอดเบิกค่าเดินทางของฉันในช่วงเดือนที่เลือก
- ยอดแยกตามค่าน้ำมัน/ค่าเดินทาง ค่าที่พัก ค่าทางด่วน ค่าจอดรถ และขนส่งสาธารณะ
- สรุปยอดระดับแผนกหรือฝ่ายที่ผู้ใช้มีสิทธิ์ดู

AI ถามผู้ใช้แบบเลือกได้ทีละขั้น: ช่วงเวลา, ขอบเขต (ของฉัน/แผนก/ฝ่าย), หน่วยงาน และยอดรวมหรือประเภทค่าใช้จ่าย ผู้ใช้ยกเลิกได้ทุกขั้น ระบบใช้ช่วงเดือนปัจจุบัน/ก่อนหน้า, 3 เดือนล่าสุด, ปีปัจจุบัน หรือเดือนย้อนหลัง 12 เดือน

## ขอบเขตและความปลอดภัย

- Capability ผูกกับ Project `LAOO_MY`, Menu `66001` (“เบิกค่าเดินทาง”), ScreenType 4, Action `VIEW` และตรวจ AI Chat, การเปิด capability, สิทธิ์เมนู และสิทธิ์ข้อมูลซ้ำใน API
- รายงานอ่านอย่างเดียว ตัวตนบริษัท/ผู้ใช้มาจาก session เท่านั้น API จำกัดช่วงไม่เกิน 12 เดือน และคืนเฉพาะยอดรวม ไม่คืนรายชื่อพนักงานหรือใบเบิก
- แผนก/ฝ่ายต้องเป็นหน่วยงานในบริษัทที่ผู้ใช้เข้าถึงได้ และ API กรองแต่ละใบเบิกด้วยกติกาสิทธิ์ข้อมูลของเมนู 66001 อีกชั้น
- Migration เพิ่ม capability พร้อมตัวอย่างถาวร แต่ตั้ง `IsEnabled=0` ต่อบริษัท เพื่อให้ผู้ดูแลเปิดใช้งานใน 10008 ตามนโยบายของบริษัท

## แนวทางต่อยอด

ระยะถัดไปอาจเพิ่มการแจ้งเตือนใบเบิกที่ยังไม่ส่ง, ตรวจรายการซ้ำหรือยอดผิดปกติ, สรุปสถานะอนุมัติ, เปรียบเทียบเดือนต่อเดือน และตอบคำถามจากระเบียบเบิกพร้อมลิงก์หน้าอ้างอิง โดยแต่ละเรื่องควรมีสิทธิ์และแหล่งข้อมูลเฉพาะของตนเอง
