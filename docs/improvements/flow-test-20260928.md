## Flow และบัญชีเคสที่ต้องทำต่อ

รายการต่อไปนี้เป็นขอบเขตตรวจ ไม่ใช่หลักฐานว่าทดสอบผ่านแล้ว ต้องแตก Case ID ผูก MenuCode/Requirement และตรวจ Source จริงก่อนทดสอบ

| ระบบ | Flow หลัก | เคสแยกที่ต้องตรวจ |
|---|---|---|
| Service | ตั้งค่า → ขอรับบริการ → มอบหมาย → ดำเนินงาน → ปิดงาน → ประเมิน → รายงาน | ผู้แจ้งแต่ละประเภท, QR, ผู้รับผิดชอบ, วัสดุ/คลัง, ยกเลิก, event ซ้ำ, fallback แบบประเมิน |
| Meeting | จอง → อนุมัติ → เชิญ → ตอบรับ → เตรียมห้อง → Check-in → อาหาร → คืนห้อง → รายงาน | ประชุม/อบรม, เวลาทับซ้อน, ปฏิเสธ/ยกเลิก, no-show, อุปกรณ์, เลือกแบบประเมิน 3 ประเภท, คืนซ้ำ |
| Training | รอบจาก Booking → ผู้เข้าอบรม → PRE/POST → จบอบรม → ผลสอบ → ประเมิน | ไม่เลือกสอบ/เลือกสอบ, เวลาเปิดปิด, ผู้ไม่ตอบรับ/ไม่ check-in, ส่งข้อสอบซ้ำ, หลักสูตร/วิทยากร |
| Time | ตั้งกะ/ปฏิทิน → ตารางงาน → ลงเวลา → คำนวณ → แก้เวลา/ลา/OT → อนุมัติ → ปิดงวด/ส่งออก | กะข้ามวัน, วันหยุด, ลงเวลาซ้ำ/ขาด, สิทธิ์ลา, ทับซ้อน, ยกเลิก, งวดปิด และขอบเขตพนักงาน |
| Visitor | ตั้งค่าจุด → นัดหมาย/Walk-in → อนุมัติ → Check-in → ยืนยันเข้าพบ → Check-out → ประวัติ | ผู้รับรองแต่ละประเภท, หลักฐาน, ผู้ดูแลจุดติดต่อ, ยืนยันซ้ำ, ออกซ้ำ, รายการผิดปกติ |
| Vote | สร้างหัวข้อ → ผู้โหวต → ส่งอนุมัติ → เผยแพร่ → ตรึงสิทธิ์ → โหวต → ปิด → ผล | ทั้งหมด/แผนก/รายคน, ส่งกลับ, เปลี่ยนโครงสร้างหลังส่ง, โหวตซ้ำ, ก่อน/หลังเวลา, นิรนาม/เปิดเผยชื่อ |
| Evaluation | ประเภท/Template → ค่าเริ่มต้น → รอบ → อนุมัติ → ตอบ/แก้ → ปิด → ผล | คำถาม 4 ชนิด, required/optional, event ซ้ำ, Snapshot, ผู้มีสิทธิ์จากต้นทาง, anonymous threshold |

ทุก Flow ต้องมี no-permission, cross-company, invalid-status, duplicate, invalid-reference, API failure, list/card/popup/filter/pagination/responsive และตรวจข้อมูลต้นทาง-ปลายทาง

## ข้อจำกัดและงานต่อ

- มีเพียงหลักฐานบัญชีทดสอบ c ในรอบนี้ ยังไม่มีหลักฐาน login ผู้อนุมัติ/ผู้ตอบ/ผู้ไม่มีสิทธิ์แยกคน
- ไม่เพิ่มสิทธิ์บัญชีจริงหรือเปลี่ยนรหัสผ่านเพื่อให้ test ผ่าน ต้องใช้บัญชีทดสอบที่เจ้าของกำหนด
- ยังไม่มี Browser automation ที่ใช้งานได้ในชุดทดสอบนี้ ไม่ใช้ API 200 แทนผลหน้าจอ
- Master ประเภทประเมินและค่าเริ่มต้นตามประเภทบริการยังไม่ได้ implement; ต้องอนุมัติ schema และ Draft ตามแผน
- ไม่รวม Gate Pass, 5S, Survey, Expense, Project, Intranet, Sales, POS ซึ่งพ่อให้พัก
- ไม่มี Schema migration, commit หรือ push ในรอบทดสอบนี้
