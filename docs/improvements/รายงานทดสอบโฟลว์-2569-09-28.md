## การแก้ระหว่างทดสอบ

1. Service Settings อ่านค่า SQL ที่คืนเป็น `int` ได้แล้ว เดิมตอบ 500
2. Vote Target Options ใช้ชื่อคอลัมน์จริง `NameTH/NameEN/UnitCode` และ `FullName` เดิมตอบ 500
3. Training Results เรียงข้อมูลหลัง `GROUP BY` ได้ถูกต้อง เดิม Booking 99/105 ตอบ 500
4. Time Test ปรับจำนวน Route เป็น 33 และเลื่อนหน้าจอก่อนตรวจหัวข้อที่อยู่ต่ำกว่าพื้นที่แสดงผล
5. Meeting คืนห้องปิด SQL reader ก่อนอ่านแบบประเมินที่เลือก เพื่อรองรับ Connection ที่ไม่ได้เปิด MARS
6. Meeting `24003` แก้ลำดับ SQL `OUTER APPLY`/`WHERE` ที่ทำให้ API 500 และให้คะแนนเฉลี่ยเป็น `null` เมื่อผู้ตอบต่ำกว่า 5 คน; หน้า Flutter แสดง `-` แทนคะแนนที่ซ่อน
7. Service test ที่คาดปุ่ม 14px เดิมไม่ตรงมาตรฐาน Typography ใหม่ซึ่งกำหนด 13px จึงแก้เฉพาะ Test แล้วผ่าน; ชุด Service ที่ไม่รวมภาพ Golden หน้า Login ผ่าน 45/45, Visitor ผ่าน 2/2; Golden Login desktop/mobile ยังไม่ผ่านและยังไม่ทับภาพอ้างอิงโดยไม่ตรวจดีไซน์

ปรับเมนู 20005 ตามคำสั่งพ่อแล้ว: ScreenType 3 ในฐานข้อมูลและ Route Contract, Permission ใช้งานเฉพาะ VIEW; บัญชี c ยังเห็นเมนูผ่าน Navigation แต่หน้า 20005 กับรายงาน 19003 ยังเป็น Placeholder จึงยังไม่นับว่า Flow ผ่านหน้าจอ Service เสร็จ บัญชี c111 ผูก Employee 10 และจุดติดต่อ Visitor ที่ใช้งานอยู่ ล็อกอินทดสอบ API ได้จริง แต่ไม่มี Project Vote

ผลเพิ่มจากบัญชีจริง: c สร้างและอนุมัติรอบประเมินทดสอบ 20 ให้ c111 ตอบและแก้คำตอบได้ โดยฐานข้อมูลมี Submission เดียวและ Notification เดียว; c111 แจ้งงานบริการทดสอบ 18, c ปิดงานแล้วเกิดรอบ Service 21 ให้ c111 ตอบได้จริง รายงานซ่อนรายละเอียดเพราะมีผู้ตอบ 1 คน Visitor ของ c111 อ่าน Check-in/Inside ได้ แต่รายงานผิดปกติ 34003 ปฏิเสธ 403 และซ่อนเมนู; Time แสดงใบลาของตน 1 รายการ ส่วน Training ของฉันแสดง 9 รายการ

ทดสอบแบบประเมินครบ 4 ชนิดเพิ่ม: Template ทดสอบ 15 และรอบ 22 ให้ c111 ตอบคะแนน 1–5, เลือกหนึ่ง, เลือกหลาย และข้อความอิสระ; คำตอบผิดเงื่อนไขถูกปฏิเสธ 400 ทั้ง 3 กรณี ชุดถูกต้องบันทึก 200 มี Submission 1 ชุด/Answers 4 รายการ และรายงานนิรนามไม่เปิดเผยรายละเอียดเมื่อมีผู้ตอบ 1 คน

## เกณฑ์ก่อนสรุปว่าเสร็จ

- c และ c111 ครอบคลุมผู้อนุมัติ ผู้ตอบประเมิน พนักงาน และผู้ปฏิบัติงานจุด Visitor แล้ว; ยังต้องมีผู้รับรองอีกบัญชี ผู้โหวตที่มีสิทธิ์ Project Vote และผู้ใช้ต่างบริษัท โดยไม่เปลี่ยนสิทธิ์งานจริง

- ไม่ได้ Commit/Push หรือรัน Migration ในรอบนี้
