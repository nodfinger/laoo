# สิทธิ์ผู้ตรวจทานองค์ความรู้

- ไม่ใช้สิทธิ์ระดับย่อย `REVIEW_KNOWLEDGE` ผู้ตรวจทานต้องเป็นพนักงานที่มีผู้ใช้เปิดใช้งานในบริษัทเดียวกันและมีสิทธิ์เมนูกล่องตรวจทาน `49004` ตามการทำงานที่ต้องใช้
- การเปิดรายการและไฟล์ตรวจสอบสิทธิ์ `VIEW`; การเผยแพร่และส่งกลับตรวจ `PUBLISH` หรือ `RETURN` ตามลำดับ
- กรณีกำหนดรายบุคคล ต้องเป็นผู้ตรวจที่กำหนดในนโยบายและได้รับมอบหมายในรายการ กรณีจำกัดฝ่ายหรือแผนก ต้องตรงกับสังกัดของผู้จัดทำตามนโยบายปัจจุบัน
- อ่านสิทธิ์และสังกัดปัจจุบันซ้ำเมื่อใช้งาน เพื่อให้การถอนสิทธิ์หรือย้ายฝ่ายมีผลทันที
