# Core Impact: หน้าอ่านใบขอนำทรัพย์สินออกผ่าน QR

## ความต้องการ

จุดนำของออกใช้กล้องมือถือสแกน QR เพื่อเปิดข้อมูลใบขอ รายการ รูปและไฟล์แนบ โดยไม่ติดตั้งแอปและไม่เข้าสู่ระบบ หน้าอ่านข้อมูลอย่างเดียวและไม่บันทึกการตรวจออก ผู้ถือ QR ทุกคนสามารถดูข้อมูลที่เปิดเผยผ่านลิงก์ได้

ใบขอที่บันทึกแล้วรวมถึงแบบร่างสร้าง QR ได้ โดยแสดงสถานะจริงอย่างชัดเจน ผู้มีสิทธิ์ในระบบเลือกเวลาหมดอายุได้ ค่าเริ่มต้นหนึ่งวันและปรับได้ในตั้งค่าระบบนำของออก การออก QR ใหม่ยกเลิกรหัสเดิมของใบเดียวกัน

## สิ่งที่ต้องให้ Core กำหนดและเชื่อม

- เส้นทางสาธารณะสำหรับหน้าอ่านเอกสารและการเข้าถึง API/ไฟล์ โดยไม่ผ่านหน้า Login และไม่เปิดสิทธิ์ให้เข้าถึงข้อมูลหรือ API อื่น
- รูปแบบ URL และโดเมน HTTPS ที่มือถือจุดนำของออกเข้าถึงได้ รวมถึงการตั้งค่าใน Center host และ reverse proxy
- สัญญาการใช้ token สำหรับการออก ยกเลิก หมดอายุและเข้าถึงเอกสารกับไฟล์แนบ การจำกัดคำขอ การเก็บ log โดยไม่บันทึก token และการป้องกันข้อมูลหลุดผ่าน cache, referrer และ log
- Action/Permission ที่ใช้อนุญาตสร้างและยกเลิก QR รวมทั้งการตรวจบริษัท แพ็กเกจ และขอบเขตเอกสารของผู้สร้าง
- ข้อกำหนดการตอบเมื่อ token หมดอายุ ถูกยกเลิก เอกสารถูกลบหรือบริษัทปิดใช้งาน โดยไม่เปิดเผยข้อมูลเอกสาร

## ขอบเขต Project หลัง Core พร้อม

ระบบนำของออกรับผิดชอบ migration และข้อมูล token ของตนเอง การบันทึกค่าหมดอายุและการยกเลิกรหัสเดิม API ข้อมูลเฉพาะใบขอ หน้าอ่านและไฟล์แนบ ปุ่มออก QR และการแสดง QR ในแบบพิมพ์ พร้อมตรวจเงื่อนไขของ Core ทุกครั้ง

ค่าตั้งต้นอายุ QR เป็นข้อมูลของ Project ใน `dbo.TDGPSetting.DefaultQrExpiryDays` คอลัมน์เริ่มต้น 1 วันและกำหนดช่วง 1–365 วัน การแก้ค่านี้ไม่เปลี่ยนวันหมดอายุของ QR ที่สร้างไปแล้ว

การพัฒนาและเปิดใช้งานส่วนสาธารณะต้องรอ Core contract และการเชื่อม Center host พร้อมก่อน ห้ามใช้ `localhost` เป็น URL สำหรับผู้สแกนบนมือถือ
